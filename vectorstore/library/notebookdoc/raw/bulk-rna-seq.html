K-Means Clustering for RNA-Seq data

This notebook performs K-Means clustering on RNA-Seq data (including the necessary preprocessing and visualization). The K-Means clustering algorithm is a clustering technique which divides the provided data into K groups and assigns each data point to the closest cluster centroid (mean).
