Single-Cell GenePattern Resources Overview
GenePattern is a computational platform for single-cell RNA sequencing analysis
GenePattern provides multiple computational tools for different stages of single-cell analysis
The platform supports various analysis workflows including preprocessing, alignment, quality control, and visualization
Getting Started Resources

Preprocessing and Alignment Tools
STAR aligner maps RNA-seq reads to genome
Kallisto performs transcript-level quantification
HISAT2 enables mapping of sequencing reads to reference genomes
TopHat supports splice junction mapping for RNA-Seq reads
Quality Control and Filtering Tools
FastQC generates sequencing data quality reports
Seurat QC explores cell-level quality metrics
Trimmomatic trims low-quality reads and adapter sequences
HTSeq.Count processes alignment files
