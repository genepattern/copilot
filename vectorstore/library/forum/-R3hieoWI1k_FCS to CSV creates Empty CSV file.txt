A user encountered an issue converting a mass cytometry (Cytof) FCS file to CSV using GenePattern's FcsToCsv module, which resulted in an empty CSV file due to a technical problem with the FCS file header; the module author diagnosed the issue as a one-byte offset in the file's TEXT segment boundary, and provided several potential solutions including using FlowJo for conversion, manually fixing the file header in a binary editor, using R with flowCore library, or requesting the original software vendor (Fluidigm) to correct their file output format.
