A researcher sought guidance on analyzing targeted/amplicon sequencing data from FFPE tumor samples, specifically requesting GenePattern tools for downstream analysis of VCF files from CNV and mutation calling to generate comparative plots between untreated and treated samples; an expert recommended MutSigCV and MutPanning tools for analysis, suggested using Integrative Genomics Viewer (IGV) for visualization, and noted that VCF files would need conversion to MAF format, though ultimately cautioned that these tools are more suited to whole genome or whole exome sequencing data rather than targeted amplicon sequencing.
