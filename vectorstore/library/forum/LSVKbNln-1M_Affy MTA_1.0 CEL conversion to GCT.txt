A GenePattern user encountered difficulty converting Affymetrix Mouse Transcriptome Array 1.0 (MTA 1.0) CEL files to GCT format for GSEA analysis due to module incompatibility, specifically with AffySTExpressionFileCreator and ExpressionFileCreator not recognizing the array type; the GenePattern team subsequently updated the AffySTExpressionFileCreator module to accept Clariom arrays, resolving the original conversion issue and enabling successful file format transformation.
