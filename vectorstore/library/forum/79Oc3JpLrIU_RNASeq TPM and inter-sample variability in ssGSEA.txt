GenePattern forum thread about RNASeq TPM and ssGSEA involving key recommendations for processing RNA-seq data: Use TPM values for ssGSEA to correct gene length bias, first run ssGSEA and then check for batch effects, with the default "sample normalization method" typically recommended; batch correction can be done by removing mean batch shift from log2(TPM) data if clustering by batch persists, and the "combine mode" in ssGSEA allows merging of up and down-regulated gene sets with options like combine.replace and combine.add depending on specific analysis needs.
