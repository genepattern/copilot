A GenePattern forum user sought help converting Affymetrix Clariom_S_Human CEL files to a GCT file for GSEA analysis, encountering errors with ExpressionFileGenerator and AffySTExpressionFileCreator modules; the GenePattern team acknowledged the issue and released an updated version of AffySTExpressionFileCreator in February 2021 with support for Clariom arrays, resolving the user's initial conversion challenges.
