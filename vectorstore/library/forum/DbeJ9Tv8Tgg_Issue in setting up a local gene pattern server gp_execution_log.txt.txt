A user encountered an issue with GenePattern server where job status showed as "Error" despite successful analysis completion, with the gp_execution_log.txt file missing; the solution involves checking the "Show Execution Logs" checkbox and modifying the config_custom.yaml file to adjust error handling settings, specifically setting job.error_status.stderr to false and job.error_status.exit_value to true, then reloading job configuration from the administration page.
