A user experienced a segmentation fault error when using the ExpressionFileCreator module for Affymetrix microarray data, specifically with a Clariom S Mouse array. The recommended solution was to use the AffySTExpressionFileCreator module instead, which successfully processed the files. Additionally, a chip file for converting Mouse Clariom S array data to human gene symbols was provided for use with GSEA, with the understanding that full Clariom array support is still being investigated by the GenePattern team.
