Gene Set Enrichment Analysis (GSEA) troubleshooting for bulk RNA-seq data involving mouse cell lines, focusing on correct input file preparation, chip annotation selection, and recommended practices: use full gene list (not filtered), all sample replicates (not averages), appropriate chip file (Mouse_Gene_Symbol_Remapping_Human_Orthologs_MSigDB.v7.4.chip), set permutation type to "gene_set" for 3 vs 3 experiment, avoid special characters in filenames, and use most recent MSigDB version (7.4).
