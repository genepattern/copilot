The forum thread discusses how to automatically label output files with gene signature names when using ssGSEA in batch mode via the GenePattern web application, with the conclusion that there is currently no built-in method to accomplish this, though a potential workaround might be using a notebook to rename files programmatically. The key finding is that despite attempting to use <gene.sets.database.files_basename> as an output prefix, the desired file naming was not achieved due to the way GenePattern generates file lists.
