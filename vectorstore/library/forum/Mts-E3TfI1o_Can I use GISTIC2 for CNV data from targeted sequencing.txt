Targeted sequencing CNV data analysis using GISTIC2: User asked about applying GISTIC2 to copy number variation data from a targeted 1.2 Mbp panel with 33,524 probes covering 382 genes, generated using CNVkit. While the user successfully ran GISTIC2 on GenePattern without errors, there was uncertainty about the algorithm's appropriateness for targeted sequencing data, which differs from whole genome or whole exome approaches. The GenePattern support team recommended consulting the GISTIC forum directly for expert guidance on the method's suitability for this specific experimental design.
