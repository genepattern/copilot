Thread summary for GenePattern forum: A researcher was experiencing a GISTIC error when attempting to run copy number analysis on whole exome sequencing (WES) data with 18 samples, encountering an "Index exceeds matrix dimensions" error. The expert responder diagnosed the core issue as extremely noisy copy number data, with most tumor samples containing 10,000-270,000 copy number segments (instead of the expected 100-1000 segments), suggesting significant problems with either the sequencing process or the copy number calling algorithm. The recommendation was to troubleshoot the copy number generation pipeline, as the current data is too fragmented for GISTIC analysis, and the software cannot effectively process such highly segmented data.
