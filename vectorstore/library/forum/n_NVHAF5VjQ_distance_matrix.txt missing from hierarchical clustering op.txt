A user encountered an issue with the hierarchical clustering module in GenePattern where the distance_matrix.txt file was not being generated during clustering analyses across multiple jobs, with a minor fontconfig warning present. The support team investigated the issue, resolved the fontconfig warning in version 7.9, and confirmed that distance matrix generation was working for small datasets, with the output now being in CSV format instead of the expected TXT format. The developer requested additional context about the user's intended use of the distance matrix to better understand the underlying requirements.
