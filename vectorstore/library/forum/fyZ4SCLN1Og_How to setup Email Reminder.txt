GenePattern email configuration thread summary: A user was experiencing issues setting up email reminders on a GenePattern server, specifically with SMTP configuration for Gmail. The solution involved configuring SMTP settings in the config_custom.yaml file, including server, authentication credentials, and JavaMail properties. After resolving the initial email configuration, the user then sought to modify the base URL in email job result links from localhost to a web server domain, which could be addressed by updating the fqHostName and GenePatternURL keys in the genepattern.properties file.
