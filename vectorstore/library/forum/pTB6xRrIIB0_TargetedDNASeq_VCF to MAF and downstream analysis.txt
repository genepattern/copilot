A user asked about analyzing Targeted DNA Sequencing data in GenePattern, specifically: 1) identifying the best module for analysis, 2) converting VCF files to MAF format, and 3) generating mutation-related plots. The response suggested MutSigCV as a potential module, but noted it might not be ideal for targeted sequencing data. For VCF to MAF conversion, no native GenePattern module exists, with an external tool (vcf2maf) recommended. The user was advised to contact the module's original author for definitive guidance on using MutSigCV with targeted sequencing data, as its primary design targets whole genome/exome sequencing.
