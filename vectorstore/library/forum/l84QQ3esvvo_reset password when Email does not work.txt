GenePattern forum thread summary focused on troubleshooting email password reset functionality: A user encountered issues with GenePattern's password reset mechanism, specifically that emails were not being sent despite correct SMTP server configuration. The resolution involved manually specifying an accessible SMTP server in the config_custom.yaml file, and an administrator can directly modify user accounts through SQL commands accessible via the /gp/sql.jsp page, including updating email addresses and deleting user accounts, though direct password modification is not possible due to encryption.
