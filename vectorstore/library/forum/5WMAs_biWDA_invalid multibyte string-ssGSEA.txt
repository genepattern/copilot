ssGSEA gene expression analysis troubleshooting thread summary: User encountered an "invalid multibyte string" error when attempting to run ssGSEA, which was ultimately resolved by resaving the input GCT file from Excel as a tab-delimited text file, ensuring proper file formatting; additionally, a subsequent user learned that ssGSEA has an internal gene set size limit of 2,000 genes, which can cause processing errors if exceeded.
