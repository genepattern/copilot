A GenePattern user was experiencing issues generating a GCT file from Affymetrix CEL files, specifically with the ExpressionFileCreator module, encountering an annotation error for the Clariom_S_Human chip. The user later discovered the online version of GenePattern does not support IVT (Affymetrix) array CEL files and only allows ST arrays, and experienced technical difficulties trying to download an older version of the software. A GenePattern team member suggested alternative module links and offered assistance in resolving the file conversion problem.
