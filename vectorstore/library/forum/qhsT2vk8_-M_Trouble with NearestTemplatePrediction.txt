A GenePattern user encountered issues running the NearestTemplatePrediction module, with the primary problems being: (1) file was saved in UTF-16 encoding instead of the more standard UTF-8, which caused compatibility issues with R, and (2) an unnecessary header for cox scores was present in the input file when no actual scores were provided. After changing the file encoding to UTF-8 and removing the unnecessary header, the user was able to successfully run the NearestTemplatePrediction analysis.
