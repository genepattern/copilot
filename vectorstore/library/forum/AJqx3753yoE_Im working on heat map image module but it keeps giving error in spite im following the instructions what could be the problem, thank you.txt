Summary of GenePattern help forum thread: A user was experiencing issues with the HeatMapImage module in GenePattern, encountering file format errors when attempting to create a heatmap visualization. The initial problem was using an incorrect file type (ODF instead of GCT), and later discovered to be a file saving issue where the .gct file was incorrectly saved with a .txt extension. Recommended solutions included using the HeatMapViewer module as an alternative visualization tool and ensuring proper file saving with quotes to maintain the correct file extension.
