The GenePattern forum thread describes a user experiencing an error when attempting to create a constellation map from ssGSEA results, specifically a gene set matching error involving mismatched MSigDB collection versions (h.all.v5.1.symbols.gmt vs h.all.v6.1.symbols.gmt), with the recommended solution being to rerun ssGSEA using the older GMT file version and to use the 'combine.off' mode to prevent gene set name mismatches; the key technical recommendation is to ensure consistent gene set database versions between analysis modules and to avoid automatic gene set splitting/combining.
