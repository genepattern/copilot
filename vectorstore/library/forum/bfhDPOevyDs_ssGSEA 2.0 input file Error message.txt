A GenePattern forum user encountered an error when running ssGSEA 2.0, which was caused by mismatched identifiers between the input GMT and GCT files, specifically with suffixes ';u' and ';d' present in the GMT file but not in the GCT file; the recommended solution was to modify the GMT file identifiers to match the GCT file format by removing the extra suffixes, which should resolve the input file compatibility issue.
