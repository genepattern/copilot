User encountered an error when attempting to use JavaTreeView visualizer with CDT/GTR files generated in GenePattern, specifically receiving a "LoadException" with a NullPointerException; support team investigated file formatting issues, finding an extra blank line and extraneous tab character in the CDT file which were causing visualization problems; after removing these formatting errors, both JavaTreeView and HierarchicalClusteringViewer successfully loaded the files, resolving the initial error.
