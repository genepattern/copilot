User encountered an HTTP 500 Internal Server Error when attempting to run Pre-ranked GSEA programmatically via the GenePattern Python API, with the specific error occurring during job submission. The root cause was identified as a memory specification formatting issue (extra space in "4 Gb" vs expected "4GB"), and while a complete resolution was not found, a temporary workaround was to comment out custom memory settings or use the web interface for job submission. The GenePattern team acknowledged the bug and planned to deploy a fix within 1-2 weeks.
