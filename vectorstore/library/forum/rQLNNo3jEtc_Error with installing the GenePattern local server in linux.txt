A user encountered installation errors for GenePattern version 3.9.10 on multiple Linux distributions (CentOS 6.7, Ubuntu 14.04, Ubuntu 16.04) using Oracle JDK 7, and was advised to perform a headless installation by placing the install-gp.properties file next to the GPserver.bin file, editing the file with correct values, and installing using the command `./GPserver.bin -f install-gp.properties`.
