A GenePattern user encountered an error with the Bowtie Aligner when attempting to align paired-end RNAseq reads from compressed .fq.gz files, receiving an error suggesting the input file was not recognized as a valid FASTQ file; upon uncompressing the files to .fq format, the alignment proceeded successfully, with a GenePattern developer noting they would investigate adding support for compressed file inputs or updating documentation to clarify file compatibility.
