A user experienced difficulties performing Principal Component Analysis (PCA) in GenePattern, encountering an ArrayIndexOutOfBoundsException when attempting to run the analysis. The problem was identified as twofold: potential memory allocation issues and invalid characters in the output filename. The recommended solution was to rerun the PCA analysis with 12 GB of memory and remove '<' and '>' characters from the output filename, which can interfere with GenePattern's command line processing.
