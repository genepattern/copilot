User encountered an error in the GenePattern AffySTExpressionFileCreator module when attempting to normalize and process Affymetrix microarray data, with a specific error message related to the basicRMA function involving thread creation, which was ultimately determined to be caused by a recent docker container update that silently modified the underlying operating system and caused module failure; the GenePattern team acknowledged the issue and was working on a fix, recommending users temporarily use a previous module version for non-Clariom platform arrays.
