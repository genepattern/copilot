User encountered an error while running ssGSEA on GenePattern, specifically a "subscript out of bounds" error when attempting to run an analysis with a gene set containing over 3000 genes. The GenePattern support team identified that the ssGSEA module has an internal limit of 2000 genes per gene set, and recommended restricting the gene list by applying a more stringent confidence cutoff to reduce the total number of genes to below 2000.
