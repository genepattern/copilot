GenePattern forum thread summary focused on locating the MutSigCV coverage file for mutation analysis, with users experiencing difficulty finding the required exome_full192.coverage.txt file after the Broad Institute FTP site was shut down. The solution was provided by Ted Liefeld, who pointed users to an AWS S3 hosted location at https://datasets.genepattern.org/gpftp/module_support_files/MutSigCV_1.4/exome_full192.coverage.txt, which successfully resolved the file access issue for users attempting to run MutSigCV for cancer mutation analysis.
