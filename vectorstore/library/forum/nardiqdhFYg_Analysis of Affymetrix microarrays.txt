Analysis of Affymetrix microarrays: A clinician sought guidance on converting .CEL files to .GCT format using the ExpressionFileCreator module, with a specific question about whether this module automatically incorporates background correction, normalization, and summarization. The response confirmed that the ExpressionFileCreator module is appropriate for these tasks, using the RMA (Robust Multichip Average) method for preprocessing, while the PreprocessDataset module is recommended for post-summarization analysis and variation filtering.
