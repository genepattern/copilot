GenePattern is migrating its public server from genepattern.broadinstitute.org to cloud.genepattern.org on Amazon Web Services (AWS) as of January 1, 2019, with instructions for users to backup pipelines and files, import pipelines to the new server, reset passwords, address missing modules, and understand implications for GenePattern Notebook and GenomeSpace accounts, with a new requirement that all modules run in Docker.
