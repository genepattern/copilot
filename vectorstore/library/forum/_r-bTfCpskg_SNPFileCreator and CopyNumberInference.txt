Summary of GenePattern forum thread: A bioinformatics researcher sought assistance in reconstructing an Affymetrix SNP6 Copy Number Inference Pipeline by obtaining module source code for SNPFileCreator, Birdseed, and CopyNumberInference. GenePattern support staff helped by providing downloadable code for SNPFileCreator and CopyNumberInference via cloud export and a datasets link, locating and sharing Birdseed module archives, and offering additional support in tracking down missing Java packages required for module implementation.
