A GenePattern user experienced persistent GISTIC 2.0 job processing issues between June 21-24, 2024, with jobs appearing to remain in a continuous "processing" state. The GenePattern team identified a backend computing environment problem related to file retrieval, specifically with the 'gistic_inputs.mat' file, which was preventing job completion status updates. They temporarily reconfigured the compute environment, recommended users check 'remote_stderr.txt' and 'remote_stdout.txt' files to verify actual job status, and were working on a fix to allow job completion after a maximum number of download attempts.
