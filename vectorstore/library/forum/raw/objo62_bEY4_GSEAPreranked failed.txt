Hi


I think the issue is the values of 'Inf' in your rank file.  Since this is a java implementation its looking to put those values into a float object which cannot contain infinity.


I think if you pick a very large number and replace all the 'Inf''s in your rank file it should be able to work.  The max value of a float in java is 3.40282346638528860e+38 but you might want to pick a number just a bit lower than that in case I found the wrong answer on google.  I did convert it to 9999999999999 and ran it as a test and it seemed to be able to run to completion.


Hope this helps,
