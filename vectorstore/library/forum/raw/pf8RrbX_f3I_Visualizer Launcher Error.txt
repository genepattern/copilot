I recommend that you use the latest version of the HeatMapViewer (currently v13.9). We ported it to JavaScript to avoid known issues with Java applets. It opens directly in your web browser; you don't need to use the Java Visualizer Launcher.

If for some reason you want to use the Visualizer Launcher (for example for other visualizers which have not been ported to JavaScript), double check that you are using the correct server address in the dialog box. Starting November 2018 we have a new server address:

    server: https://cloud.genepattern.org/gp
