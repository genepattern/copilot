Hi


if you already have a valid GCT file, you might want to use the ClsFileCreator module to make the matching cls file.  Its a javascript module that will run in your browser.  You give it the gct file and it reads the sample names from that, and then you can choose how to separate the samples into classes.  Here is a direct link to the ClsFileCreator


https://cloud.genepattern.org/gp/pages/index.jsf?lsid=urn:lsid:broad.mit.edu:cancer.software.genepattern.module.visualizer:00261:4.1


Let us know if this helps.  Don't forget you can click on the 'documentation' link on the top right of the module's page to see more detail about how to use it.


Hope this helps

Hi again,


one more point to deal with is that another of our team members noticed that your GCT file does not appear to be in valid GCT format.  You have 3 leading columns (id, name, description) where only 2 are expected.  You will need to delete one of them (id looks like the best to delete to my eye).  Please refer to the gct format here https://www.genepattern.org/file-formats-guide#GCT
