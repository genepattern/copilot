Hello, 


Unfortunately, as you have probably noticed, the documentation for NTP is rather lacking in its specification of log-transformed input data. However, the example data does not appear to be log-transformed, so I think it is safe to assume that this is allowed, if not preferred.


As for the two columns. Again, the documentation is a little light here, but it seems the most important thing is that the first column "Probe IDs" should match the first column of Probe IDs in your input GCT file. I would suspect that, like a GCT file, the second column is a descriptive column for humans, and thus using the same probe ids would be allowed.


Give it a try and let us know if you have any further questions.


Best
