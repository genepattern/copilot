Hello Praveen, 


The only color option for HeatMapImage is to recolor the heatmap itself. 


Please see the documentation for details: https://cloud.genepattern.org/gp/module/doc/urn:lsid:broad.mit.edu:cancer.software.genepattern.module.analysis:00032:6
As a reminder, documentation for all modules is always available from the documentation link in the upper right-hand corner of the module run page. It's also available from the gear icon in the module buttons in the panel modules & pipelines panel.


Let us know if you have any further questions or comments.


Best
-Barbara
