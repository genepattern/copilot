Hi,


there is a way but I am not sure how simple you will consider it.  You can create your own java implementation for the IAuthenticationPlugin interface.  I have not actually done it myself yet, but will be doing this myself during June where I will try to create a plugin to authenticate using OpenIDConnect.  If your institution is an OpenID Connect identity Provider (anyone using google apps for example) this should make it easier for you later this summer.


It is documented in our Administrators guide here: https://www.genepattern.org/administrators-guide#_User_Authentication_and


Hope this helps,
