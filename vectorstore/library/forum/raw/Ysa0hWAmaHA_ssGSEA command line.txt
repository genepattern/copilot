Unfortunately we don't have support for that at this time.  The module is written in R as you note, so if you are savvy with R programming you could conceivably turn it into something that runs on the command line - that is conceptually what GenePattern is doing behind the scenes.  The latest version is pure R so there's no longer any need for Java.


The code is available on GitHub or it can be exported from the GenePattern server.  Check the manifest file for hints on creating a suitable command line using Rscript.  The module lists R-2.15 as a requirement but it's quite likely it would work with newer versions of R as well (it has no additional library dependencies).  You would want to test that for yourself, of course, for example by comparing results from GenePattern to local runs.
