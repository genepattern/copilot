Hi Aracelly,

 

GSE123168 is an RNA-seq dataset. RNA-seq datasets typically don’t have their complete data in the GEO Soft file format that would be required to read them in through the GEOImporter Module. If you navigate to the GEO page for GSE123168 (https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE123168), you can see at the bottom of the page that there is a GSE123168_Count_Table.txt.gz file. You’ll need to download that file and manually convert it into the GCT format. Once you’ve done that, you can normalize it with the DESeq2 module and then use it for GSEA. Unfortunately, there is too much heterogeneity in the way Supplementary Files are included in GEO records to allow for us to implement a programmatic importer for these data.
