Hello Akshaya, 



You ran into the default wall time on the server, so the job stopped executing. 


We've increased the default wall time to 1 day for NMFConsensus, and added the ability for you to change this as well. If you scroll to the bottom the job input form, you should see a new section called "Job Options" where you can change the wall time for any module you run.


Please try running again and let us know if you have any further difficulty.
