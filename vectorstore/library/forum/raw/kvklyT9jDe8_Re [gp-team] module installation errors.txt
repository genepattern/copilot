Hi


in the past we used to have a collection of scripts to help set up the different environments for the various modules, but as you may guess that was a bit cumbersome.  The latest versions of GenePattern (last year or so) use docker containers to keep the different module environments separate.  We may not have a container for every module (especially older versions) yet, but most modules and definitely the most popular ones should be covered.


Since you are on a mac, the best thing would be to take the most recent release candidate from our github releases page (https://github.com/genepattern/genepattern-server/releases).  You will first need to install docker on your mac (https://docs.docker.com/docker-for-mac/install/), then install the new version of GenePattern and things should just work.  If you find a module that does not work that you need, post it here and we'll make sure it moves to the top of the queue for our attention.


Thanks

Ted
