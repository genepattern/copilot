Hi,


To align with changes that we implemented in GSEA Desktop Preranked, version 7 of the module allows the GSEA collapse dataset function. The default value of this collapse dataset parameter expects that you provide a chip file in order to process your gene identifiers using the Remap Only mode. This allows us to make sure that the version of Gene Symbols used in the input ranked list are consistent with the symbols used in MSigDB.


If you do not wish to provide a chip file, make sure the "collapse dataset" parameter is set to "No collapse"


This should resolve the error that you are seeing.
