Thanks for your interest in GSEA and MSigDB. This error message is usually a
result of using both a parent collection and a sub-collection (such as C2 and
CP:CP:KEGG) at the same time in an analysis run. GSEA requires unique gene set
names, but since the parent collection holds all of the items in the
sub-collection, GSEA will flag all of these as duplicates.

Just use the parent collections without any of their sub-collections and the
issue should go away.



Sincerely,
The GenePattern Team
