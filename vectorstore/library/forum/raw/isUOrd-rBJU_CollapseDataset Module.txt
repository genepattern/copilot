Hi Roser,



I'm following up to your private message to me here on the GenePattern mailing list in case the discussion will help anyone else looking for answers in the future.


The question was in regards to these warnings in the module output:
WARNING: package com.apple.laf not in java.desktop
WARNING: package com.sun.java.swing.plaf.windows not in java.desktop
WARNING: package sun.awt.windows not in java.desktop

 


Those messages are just warnings from Java that packages for the Mac and Windows user interface are not available since the program is running on Linux.  They can be totally ignored, they have no effect on the output at all and don't represent an error.


CollapseDataset is part of the GSEA Desktop program which has its own stand-alone UI.  For GenePattern we run this in a "command-line" (or "batch") mode with no user interface, but Java still notices these are missing and gives the warning.
