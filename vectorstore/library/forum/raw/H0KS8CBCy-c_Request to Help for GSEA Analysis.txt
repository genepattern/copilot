Hi Zahra,


I think I see the issue now, you actually mentioned it in your first message and I missed it. You should not use the triplicate averages for each group. You should use the data for all the replicates, GSEA will do the averaging internally, and if you don't provide it the replicates it isn't able to perform the expected math.


You'll also have the make the corresponding change to the CLS file.


Additionally with a 3 vs 3 experiment you'll want to set permutation type to "gene_set" rather than "phenotype".


Also, I'd take a close look at your CLS file name, it looks like GSEA might be doing something weird with the ' character in it. GSEA has kind of an old codebase so, out of an abundance of caution, we generally recommend against using any special characters in filenames.


Finally, your gene set database file appears to be pointing at an extremely old and unsupported version (version 6.0). The current version is 7.4 and we strongly recommend using it over the old ones. 


Likewise, your chip file is pointing at the MSigDB 7.0 version, another old file that's undergone extensive refinement in newer builds, and we recommend using the matching 7.4 version (there was a name change to include the "Human Orthologs" text in the file names, this is because all MSigDB gene sets are in human gene symbols so we have to perform conversion to make them match the gene sets). It's unusual to have a dataset using the NCBI gene ID namespace, if you want to send an example of the gene IDs from your file, I'd be happy to double check that this is the correct chip file for your data.


I think this should address the issues I noticed in your screenshots, but if you encounter further error messages please don't hesitate to reach out again.
