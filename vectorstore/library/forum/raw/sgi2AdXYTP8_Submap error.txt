All,


we have a new prototype version of SubMap (version 3.1) available on our beta server.  It seems to be working correctly but has not yet been tested to our satisfaction (hence its only on the beta server).  If you want to try it out, login to https://beta.genepattern.org.  This server has separate accounts from our production (cloud.genepattern.org) server so you may need to register again if you haven't been on the beta server before.


If you want to wait for it to be available on cloud, it should be available there some time next week.  Thanks for your patience,


Ted


p.s. The problem seems to be related to sorting dataframes in the R code.  As a workaround in some cases you will be able to run the older version of submap if you ensure that you have some variation in the description column of your gct files.  e.g. if all rows have 'na' for description, change a few tp 'na1' or 'na2'.  This does not let you past all of the 'memory not mapped' errors though.  If your stderr.txt file indicates a failure while sorting for the heatmap, you will have to wait for the new module version
