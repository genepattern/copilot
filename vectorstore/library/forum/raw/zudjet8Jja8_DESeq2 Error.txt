Hi,


I think I found your job (501454) and it looks like the problem is that the CLS file parser is reading the second line of your cls file as 4 separate class labels (and then only finds the two classes (0,1) because it uses the space (' ') as the delimiter.    I won't use your class labels here (in case its private) but you have something vaguely like


#  First class Second class


and I think if you want a compound class name you should change it to something without a space in a class name like this


#  First_class Second_class


I did a quick test and this seems to work when I rerun your job with a modified class file.


Hope this helps,
