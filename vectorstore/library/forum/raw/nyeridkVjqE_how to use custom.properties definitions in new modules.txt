Hi,
New to modules, I still have difficulties.


I installed samtools1.5 and friends and set the folder location in 'custom.properties'
'''samtools_1.5=/opt/tools/GenePatternServer/patches/SAMTools/samtools-1.5'''
How can I programatically link to the custom.properties definition of the samtools1.5 path in the module maker interface to call tabix for instance which is present in the [custom.properties/samtools1.5] location?

Is there a notation for this kind of reference like <libdir> for the module path?

You have a few options:
(1) add another entry to the custom.properties for tabix, e.g. in custom.properties
  tabix=<samtools_1.5>/bin/tabix
in the module integrator (or manifest file)
  commandLine=<tabix> ...

(2) pass the path directly on the command line, e.g.
  commandLine=<samtools_1.5>/bin/tabix ...

I am not that familiar with the tabix command, so use your best judgement.

Please send along a brief summary of how you want to use tabix. We are developing new and improved methods for integrating GenePattern with pre-installed tools such as samtools and tabix.

Regards,
Peter
