Guy,


it is possible to use your favorite database tools to talk to the Genepattern database like any other.  If you are administrator you can get the database connection details from the configuration files.  


For quick checks into the DB there is a page available only to administrators at */gp/sql.jsp which will let you execute SQL against the database.  It is pretty limited but useful for small/simple queries that don't involve blobs/clobs or other complex data types.
