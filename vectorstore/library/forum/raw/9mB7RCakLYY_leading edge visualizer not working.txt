Jay


it sounds like your installed java environment is not accepting the SSL certificate for the GenePattern server.  The fix is to install the GenePattern server's certificate into your java truststore.  Since you are at NIH and presumably have a managed environment you will probably need to contact your IT department to ask them to do this.  An alternative approach (which might have the same issue) would be to download the GSEA application from gsea-msigdb.org and see if that can run and display the leading edge viewer for you.


Hope this helps
