Hi Sandra,

 

I think I figured out the issue here. The ExpressionFileCreator module, which is quite old, doesn’t like the ZIP files created through the MacOS, right click menu “Compress” tool. This is because MacOS adds a bunch structure and hidden files to it that the script can’t parse as its current written.

 

If you need to create zip files for data like these in the future, you’re going to want to do it from the terminal using:

 

cd “/path/to/dir/with/celfiles/”

zip -r GEOID_files.zip . -x ".*" -x "__MACOSX"

 

In this case, I’ve recreated your archive using the above command and rerun the module on the new archive. You should be able to access the results here: https://cloud.genepattern.org/gp/pages/index.jsf?jobid=332073&openVisualizers=false&openNewWindow=false

Let me know if you have any issues accessing it.

 

-Anthony
