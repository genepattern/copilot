Hi again,


I don't yet have a fix but the problem seems to be that one or more of the files generated by GSEA have filenames containing characters  that our database is rejecting (SQL error 1366).  Our database is using the latin 1 character encoding.  I think its values such as the beta in 'TGFβ' from your gmt file that is causing the problem.  Try converting your gmt file to use only latin characters and that should fix the issue.  You may need to also check your gct and cls files similarly, but I think the gmt alone is causing the issue since it is the gene set names that are used for filenames, and it is the registration of the filenames that is failing.


Hope this helps


Ted
