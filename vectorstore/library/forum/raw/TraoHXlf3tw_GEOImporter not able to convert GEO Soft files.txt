Hi Chris, 


There were two issues at play.


1) I needed to connect the module to its Docker image, which I have now done.


2) You had provided a link to the FTP directory and not the soft file itself. So a simple rerun of your job will fail noting improper formatting.  To fix this, simply navigate to the ftp folder, then copy the link address of the soft.gz file and provide that as your input. (I've tested this and it takes a bit - about 35 minutes - but it works)


Please let us know if you have any further trouble.
