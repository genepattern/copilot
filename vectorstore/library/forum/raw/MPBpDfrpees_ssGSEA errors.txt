Hi Jean-Philippe,


Just to clarify the situation, the ssGSEA module on GenePattern is the original implementation, and it's completely unrelated to this ssGSEA 2.0 repository on GitHub.  If you are interested in that method you would need to obtain that code from elsewhere and run it outside of GenePattern.  Unfortunately we aren't able to provide any support for that.


It's not clear to me exactly what they've changed compared to the GenePattern version, so I'm not sure it's entirely accurate to call this a later version of ssGSEA.  Perhaps "alternate implementation" would be a better term.  In any case, we (the GenePattern and GSEA teams) are not involved with it and can't vouch for it.


We can help with the ssGSEA method on GenePattern, though, and Alex's points about the GCT & GMT formatting seem like the best suggestions here.  The GenePattern module also has it's own documentation page as well.


Versioning is a little odd here.  The version numbers associated with the GenePattern module are GP-specific version numbers, and within that realm there were no separate "ssGSEA versions" at all, just the R code itself.  The "ssGSEA 2.0" nomenclature from that GitHub repository seems to be using "2.0" in the modern vernacular "new, improved" sense of the term, rather than being a specific version.  But I can't really speak for that since, again, we're not directly involved in that package.
