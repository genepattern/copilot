Hi


the problem is the format of your feature file.  There are at least 2 problems with it;
1. The columns are space separated.  The NTP documentation specifies that you need to use tabs to seperate the column values in each row
2. You have an additional column, the leftmost, which appears to be the numerical index for each row.  This is offsetting the other columns by one so that the GeneName column is being read as the class column (after the spaces/tabs are fixed)


Hope this helps


Ted
