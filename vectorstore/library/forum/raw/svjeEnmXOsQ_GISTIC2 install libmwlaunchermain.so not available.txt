Hi,


this does not seem to be a GenePattern specific error.  However the docker container I built for our GISTIC module a while back might give you a starting point for getting your container to work.  The git repo is at


https://github.com/genepattern/docker-gistic



If you look at the Dockerfile there (using older Ubuntu 14.04 and probably an older version of GISTIC too) I had to install the following OS-level libraries as well. Also it is necessary to set the LD_LIBRARY_PATH and XAPPLRESDIR.  A quick google for the missing libmwlaunchermain.so turned up this Matlab response


https://www.mathworks.com/matlabcentral/answers/267562-how-can-i-resolve-this-mcc-runtime-error-cannot-open-shared-object-library#answer_211306 


So it looks like it might be something you can fix if you get your LD_LIBRARY_PATH set correctly.


Hope this helps,


Ted
