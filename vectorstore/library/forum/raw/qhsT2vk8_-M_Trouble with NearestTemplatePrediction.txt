Hello,


After taking a second look at your files, I was able to figure out what was wrong and run NearestTemplatePrediction with them successfully.


There are two problems in Input.txt.


1) The file is saved using UTF-16 encoding. This is a fairly uncommon encoding used almost exclusively by a handful of Windows text editors. It does not work well with R, which is the language that NearestTemplatePrediction is implemented in. To get the file to work, you need to first save as using the much more standard UTF-8 encoding. I don't know which text editor you're using, but most will have that option somewhere.


2) If you do not include a weight, such as cox scores, you need to remove that header from the file. Because the header exists, NearestTemplatePrediction expects those scores to be included.
