Hi Franciele,


I've passed on that request to the (DESeq2) module developer. I am unsure as to when this feature may be implemented.


An alternative workflow to consider is this:
1- Use DESEq2 with the first CLS file (the one that separates PVEC vs ABEC). This will produce a GCT file as an output (which ends with ".normalized_counts.GCT")
2- Use this GCT file to run ComparativeMarkerSelection using your second CLS file (the one which has the conditions A, B, C, and D). This module has a parameter called "phenotype test" and you can select "all pairs" from the dropdown menu. This should give you the comparisons you are looking for. Selecting "all pairs" will create a new file for each comparison.
2.1- Note that ComparativeMarkerSelection outputs ODF files, you can use ComparativeMarkerSelectionViewer to view these results.


Please let us know if this works for you.


Edwin.
