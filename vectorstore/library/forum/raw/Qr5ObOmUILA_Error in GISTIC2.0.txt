Hi


There was a problem with the remote compute nodes that we use to execute GISTIC.  This has now be corrected and you can reload and re-run your job.


Thanks for your patience,


Ted


p.s. For the details, read on … Our GenePattern server uses several different cloud systems (both commercial and academic) to execute jobs. We attempt to keep costs down, and GenePattern free, by using less expensive, or free services to run computations when we can.  Unfortunately less expensive and free also translate into less reliable and sometimes they become unavailable as happened overnight with the service we were sending GISTIC to.  The next release of GenePattern has an automated failover so that if a job fails on one system, it can be retried automatically on another without requiring user (or administrator) intervention.
