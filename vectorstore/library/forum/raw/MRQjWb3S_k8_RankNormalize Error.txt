It should be working now on cloud.gp. Thanks for letting us know about the problem.

FYI, for other servers, if you run into this problem, here is the workaround. Set the job.docker.image in the configuration file.
    ./gp_home/resources/config_custom.yaml

default.properties:
    ...
    job.docker.image.lookup: {
        ...
        "RankNormalize": "genepattern/docker-r-2-15:0.1",
        ...
    }
    ...
