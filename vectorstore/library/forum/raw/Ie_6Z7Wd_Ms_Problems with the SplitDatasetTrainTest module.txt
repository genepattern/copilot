Hi


the problem is the value for the "output prefix" parameter which was set as "<OS>".  The angle brackets make GenePattern try to substitute the value and in this case since there is no substitution available for OS, it tries to open an output file named "" (i.e. an empty string).


If you re-run your job you can change the value to either "OS" or "<input.dataset.file_basename>" .  The first will explicitly set the output prefix, while the second will substitute the name of the input dataset up to the ".gct" part (which is also OS).


Hope this helps
