If you have not done this already go through the example from the Programmer's Guide > "Using GenePattern from Java"
Run this with an account on the public GenePattern Server to double-check that the client code is correct.

The example uses an external data file as input,
    String inputDataset = "ftp://ftp.broadinstitute.org/pub/genepattern/all_aml/all_aml_train.res";
    ...
    new Parameter("input.filename", inputDataset)
    ...


I haven't tested this with a local path in a while. For best results use a fully-qualified path.
