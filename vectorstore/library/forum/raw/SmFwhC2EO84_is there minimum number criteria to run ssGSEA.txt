Hello,

 

ssGSEA has a default minimum gene set size of 10, however this can be adjusted (it’s the second to last parameter in the main settings). We generally find that such small gene sets don’t produce substantial enrichment scores, but there shouldn’t be any technical issues with trying.

One thing to note however is that this filter is applied after matching the gene symbols in the gene set to the gene symbols in the dataset, so if there are genes in the gene set that aren’t in the dataset, that will affect the effective size of the set.
