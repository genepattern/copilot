There was a typo in the path I sent before - try the one above - you may have to unhide hidden folders in Windows - there is lots of help online if you don't already know how to do that.


I did not attempt to create a volcano plot as I'm not familiar with your data, and while we host MultiplotStudio, it is not a tool we created, nor do we maintain it, so I can only offer limited help in using it.


We did notice that in comparing the GraphPad results to the Mulitplot image it "looks like [your] axes on Multiplot are wrong. GraphPad is using -log(P value) vs log(FC), which is correct for a volcano plot. and in Multiplot [you are] plotting P value vs FC. 


We aren't sure if MultiPlot can compute the log values before plotting, though we think it may be able to. Regardless, you are not going to see the same plot if you are not using the same axes. 


Best
-Barbara
