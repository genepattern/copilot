Hello Tzu-Yu,


I believe the issue is in the way you are specifying the output file name.


Text within the carets should not be edited. So,   <mutation.table.file_LIHC> , is incorrect. This is a substitution variable and changing it means GenePattern no longer knows what to substitute. 
In order to rename your output with LIHC that field in the input form should instead be "<mutation.table.file_basename>_LIHC" (without the quotes).


This will take the file name of your mutation table file, minus the .maf extension and then add _LIHC before the extension. 


For example, if your mutation table file was MutationTableFile.maf your coverage output would be MutationTableFile_LIHC.coverage.txt

Please let us know if that helps to resolve the issues for you.


All the best
-Barbara
