Hi Taku,

 

The issue appears to be with the GCT header you're using here. It's specifying itself as a GCT v1.3 header, but this application can't handle the extra metadata that the 1.3 specification implies (even though that metadata isn't actually present based on the definition in the other header columns).

To resolve this, you should just change the first two header lines so they read:

 

#1.2

19955    48

 

This should allow ssGSEA to handle this dataset
