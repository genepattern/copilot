DESeq2 should be working again now, we are sorry for the inconvenience.  The problem was that for a while it was unable to connect to the CRAN repository.  This is a problem we see periodically and some of the old R modules (including this one) need to do some installations at the start of their runs.  We will add creating a custom docker container for this module to our queue of work, but I cannot give any idea of an ETA at the moment.  If this happens again you just need to wait a few hours for the CRAN repository to become available again, after which you can re-run your jobs.
