Hi Johanna,

 

The combined signatures are created from a union of two signatures with the same base name (e.g. RESPONSE_TO_XYZ_INHIBITION) and the suffixes _UP and _DN, so if you wanted to find the original signatures that made up the combined signature, you'd need to recreate the names (RESPONSE_TO_XYZ_INHIBITION_UP and RESPONSE_TO_XYZ_INHIBITION_DN) then download those signatures from the website and combine them manually.

 

Let me know if that answer is unclear, or you're still unable to find the original signatures.
