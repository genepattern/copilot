Annelies,


I think I found it (and had a successful run of your dataset).  The issue was the "output file prefix" parameter is being set as ".proj", and if you look at the end of the stdout.txt you will see that it did actually create ".proj.gct".  The problem is that most operating systems, and GenePattern itself, consider files that start with a dot "." to be hidden files, so it was not recognized by GenePattern as output.  If you change the value of the "output.filename.prefix" parameter to not start with the dot, you should get the expected gct file as an output in GenePattern.


Hope this helps,


Ted
