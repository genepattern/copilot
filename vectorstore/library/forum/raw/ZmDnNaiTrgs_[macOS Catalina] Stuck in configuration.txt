Francesco,


In which folder were you installing the GenePattern? I have had this problem when I attempt to install it anywhere other than the Applications folder. To fix this issue, something that has worked for me and some other team members is this two step approach:


1. Delete ~/.genepattern (you can do this from the terminal using the command rm ~/.genepattern) -- this was created the first time you ran GenePattern.app
     1.a If you had already moved GenePattern.app into /Applications, remove it from there too. 
2. Start the installation process again, but this time from within the Applications folder. I.e., put the GenePattern.app that you got from the zip into /Applications and then run it. 



Let me know if that helps.
Edwin.
