Hi Ray, 


Sorry for the late reply. 


We would suggest you to fix the identifiers in the GMT file. There are ';u' and ';d' as the suffix of the identifiers in the GMT file, but not in the GCT file. Please try running ssGSEA again after changing the identifiers in the GMT file to match the identifiers in the GCT file. 

Example: 


in the GMT file, there is the identifier:
LDGENIYIRHSNLM-p;u



In the GCT file, the identifiers look like this:
LDGENIYIRHSNLM-p



Changing the identifiers in the GMT file to match the format in the GCT file will solve the issue. 


Edwin
