Hi Scott,


Apologies for the delay in responding - as Michael mentioned, the dev team has been involved in sorting out performance issues on our production servers.


Are you using a headless install?


Create an
installer.properties file and then run ...
      ./GPserver.bin -f installer.properties

----- installer.properties example -----
#
#NOTE: if installing into a dir where there is already a GenePattern server
#      the values in this file will be overwritten by the contents of the
#      old genepattern.properties file
#
USER_INSTALL_DIR=/opt/genepattern/gp

INSTALLER_UI=silent
INSTALLER_TEMP_DIR=~/tmp
IATEMPDIR=~/tmp

Hi Scott,


I just went through this on my own Linux set-up.  Apparently there's an issue with registration on Linux.  I don't recall the details, but the workaround is to add 'registeredServer=true' to the resources/genepattern.properties file.


Be sure to stop the server first and restart after.


Hope that helps!
