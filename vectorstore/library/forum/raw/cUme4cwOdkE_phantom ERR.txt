I am not that familiar with all of the details. For starters, change the debug level. Edit the resources/log4j.properties file and restart your server. These statements show up in the genepattern.log file E.g.


# debug JobRunner API
log4j.logger.org.genepattern.server.executor.drm.JobExecutor=DEBUG


# this line for debugging a particular job runner implementation
# Note: use the fully qualified package or classname for your job runner
#  example package name 
log4j.logger.org.genepattern.server.executor.slurm=DEBUG
#  example class name 
log4j.logger.org.genepattern.server.executor.slurm.SlurmJobRunner=DEBUG
 
Look at the JobExecutor source code to see what is logged from the GenePattern Server side of things. This is also a good reference for how to add debugging statements to your java code.


    https://github.com/genepattern/genepattern-server/blob/develop/src/org/genepattern/server/executor/drm/JobExecutor.java



The SlurmJobRunner has sparse debugging statements, but there is one example:


    https://github.com/genepattern/genepattern-server/blob/develop/gp-slurm-queue/src/org/genepattern/server/executor/slurm/SlurmJobRunner.java
