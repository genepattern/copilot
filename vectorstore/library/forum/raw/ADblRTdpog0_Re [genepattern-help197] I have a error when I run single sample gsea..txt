Hi,


There is a known bug in ssGSEA when all the values in a given row contain the same value, and the error message is not very obvious for this (for non-experts in R, anyway).  The common case would be all zeroes across a row but I don't believe it's a limited to that.


We just provide the ssGSEA method as a GP module, but we're not the original developers.  However, you might try filtering out those all-zero rows.  I'll send off a note to the original author to see if we can get more info on the validity of this.
