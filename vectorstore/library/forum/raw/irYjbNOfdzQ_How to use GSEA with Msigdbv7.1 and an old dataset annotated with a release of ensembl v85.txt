Older versions of Ensembl than the one used in that MSigDB release should work perfectly fine.


So, your Ensembl 85 analysis when used with the MSigDB 7.1 chips will have their Gene IDs mapped to the Gene Symbols that were used in Ensembl 99. This is perfectly fine.


In theory, Ensembl Gene IDs are stable enough that this could also work with newer Ensembl versions (like the current Release 100) and it would map back the Ensembl 100 genes to their Ensembl 99 symbols.


Ensembl 85 is old enough that you *might* benefit from reanalyzing with a newer transcriptome anyway, but as long as you're working in the Ensembl Gene ID namespace, you don't have to do anything special to get it to work with MSigDB other than use the correct CHIP file for the identifiers.
