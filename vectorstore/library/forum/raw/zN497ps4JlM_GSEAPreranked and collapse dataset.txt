Hi Jonelle,

That documentation link applies to an older version of GSEA Preranked.  The latest version is here, which is the same as the link from the Job Submit page (in the grey module title bar).

The Collapse Dataset feature has been removed from GSEA Preranked as it often led to confusion among our users.  The primary issue here is that the user can choose whatever metric is desired to rank the entries in the dataset, but there's no guarantee that either of the collapse-to-max or collapse-to-median choices we provided are valid given that metric.


Our new recommendation is that users collapse these rows during the ranking process to ensure the collapsing method is appropriate given the chosen metric.  We may revisit this in the future if we can find a way to balance the concerns and avoid any confusion, though it's not clear when or if that will happen.

Note that older versions of GSEA Preranked are still available from the Version drop-down (also in the grey module title bar) If you are very confident that one of these collapsing modes is appropriate for your ranking metric.

One more minor note...


The collapse-related messages in the log are due to the data being run through a common section of code, used by both the GSEA Preranked method and the usual GSEA method.  You are correct that no collapsing is being done.  This message:
 No probe set => gene symbol collapsing was requested,...

should be read as "No 'probe set to gene symbol' collapsing was requested...", that is, "no collapsing was requested".
