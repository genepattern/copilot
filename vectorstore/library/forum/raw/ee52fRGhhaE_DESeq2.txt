Hi,


it took a bit of time to figure out the problems here.  They all revolved around file formatting and parsing.


First in the cls file, you need to add a space after the '#' and before the first class name ("e.g. "# r nr" and not "#r nr")


Second, there's a line in the GCT with no Name or Description (at line 536), which I found by loading a TXT version of the file in R (basically the same content but without the first two lines:

           > df <- read.table(file = "~/Downloads/GDS4551.txt", header = TRUE, row.names = NULL) Error in scan(file = file, what = what, sep = sep, quote = quote, dec = dec, : line 534 did not have 35 elements


So the code is was choking when trying to create a Data Frame.  This can be 'corrected'  by tossing in "Foo"  or ideally the real gene name/description into the Name and Description columns..  


Third,  there was also a line with a Name & Description of "NA" (at line 116):
            > which(is.na(df$Name)) [1] 113


You can fix this by changing "NA" to "NAFoo" (or anything other than NA.  This is actually a bogus fix because there really is a gene named NA, albeit non-human.  Nonetheless, this is an issue with the code & data that comes up sometimes since NA is a special value in R).  


It's possible use a similar trick to walk through each of the columns to look for NA or missing values in the data matrix, but that wasn't necessary here.


Lastly, there seems to be an issue with parsing GCT sample names that contain '.' characters. Switching these to underscores seems to solve the problem and allows the analysis to complete.


Hope this helps,


Ted (with most of the input from David Eby who wrapped DeSeq2 as a module)
