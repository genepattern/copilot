You can download the module from the GenePattern Server.
    1) Log in to GenePattern (https://cloud.genepattern.org/gp/)
    2) Click the 'Modules' tab and enter or select ComparativeMarkerSelection. This takes you to the module input form.
    3) Click the gear menu on the module input form and 'Export' the module as a zip file.

In general, recently released modules (and pre-releases) are available as GitHub releases.
  Note: CMS v10.1 is not in GitHub. You should get it from the GP server.
  Note: pre-release modules may not be fully vetted. For best results, double check the latest version that is installed on the cloud.gp server.

    1) Go to the GenePattern GitHub repository, https://github.com/genepattern
    2) Enter the module name in the "Find a repository ..." box. This will show a link to the github repo for the module. E.g.
        https://github.com/genepattern/ComparativeMarkerSelection
    3) From the GitHub repo for the module, click the 'releases' link, E.g.
        https://github.com/genepattern/ComparativeMarkerSelection/releases
