Hi Vincent, 


Thanks for alerting us to this.


It's weird that you weren't able to find it on the Broad server last week. I'm not seeing anything on the backend to indicate that it was unavailable, but that is not to say that I doubt you; I'm just unsure as to why that would have been.


In any case, as you know, we're moving off of the Broad-hosted server, so it's good that you went looking on cloud.gp.


Unfortunately, that module does not have a suitable Docker container (which is now required), and it is not a module that we developed, and the author is not interested in Dockerizing her modules. That being said, we intend to support legacy modules when and where we can and this one is a pretty simple utility, so we may be able to get it working before the end of the year.


In the meantime, you could use SelectFeaturesColumns to do that same thing, though in logical reverse - IE you must specify what to keep, rather than what to get rid of.


We'll let you know if we are able to get removeSamples correctly configured for the new AWS Batch environment.


As for IU - they will need our Docker information before they can get the module working in Singularity, so we'll keep them in the loop as well.


Please let us know if you run into anything else.


Best
Barbara
