Hi Amy, 


Multiplot was deprecated by the author and replaced with Multiplot Studio. I've installed Multiplot Studio on our Amazon Cloud server - https://cloud.genepattern.org/.


In case you have not seen our communications, the Amazon Cloud server is now our production GenePattern server, and will be turning off the job queue on our Broad GenePattern server on December 1 in preparation for its decommission on  January 1, 2019. 


So, if you've not yet created an account on that server, I would suggest doing so now.


Please note that Multiplot Studio is an older Java applet visualizer and therefore requires the use of our Visualizer Launcher.


Let us know if you have any questions or comments.


Best
-Barbara
