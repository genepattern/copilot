Hello Hossein,

This output confirms that your system is running an incompatible version of Java. The VisualizerLauncher requires Java 8, whereas your system is running Java 18. 

Unfortunately Java 11 introduced many breaking changes to the Java bytecode, causing many older Java programs to no longer function with the newer runtime environments. Java 18 inherits those breaking changes from Java 11.

GenePattern Team
