Hi Ravi,


1. You should use TPM values for input to DiSCoVER. 


2. DiSCoVER is designed to run on one treatment/control pair at a time, so there should not be different treatment groups in the treatment .csv file.


Please let me know if I can answer any other questions.


Best,
