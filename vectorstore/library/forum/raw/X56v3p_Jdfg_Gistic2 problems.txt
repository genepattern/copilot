Hi


This can happen sometimes when demand on the GenePattern servers is high.  Lately we have had several users running batches of 50-200 jobs against the public Genepattern server.  When this happens we can get the error you see because the machines are running so non-stop they cannot be recycled (we use leased cloud-hosted machines from AWS).  If you can afford to wait, the best thing to do  is to wait a few hours and then resubmit your job.  It may sometimes work to change the cpu count and memory requested if you cannot wait, but this is not guaranteed to work. If you  yourself are running batch jobs and hitting this frequently then we can help you set up your own GenePattern server where you will not affect, or be affected by, other users.


Hope this helps,


Ted
