If you want to open a GCT file, you can open it in Excel by selecting the "tab delimited" option (as Mitchell Frederick has mentioned). It is possible that the GCT file you are trying to use has been corrupted, try to delete it and uncompress the TAR file you have.


If all you want to do is view the contents of the GCT file, you can also open it in a text editor (and this is often easier to do than in Excel).



For more information on GCT files, you can check this link: https://software.broadinstitute.org/cancer/software/gsea/wiki/index.php/Data_formats


If you are still having problems, please let us know more details (e.g., what happens when you try opening the file and what steps are you taking to do so).
