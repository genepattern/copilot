Hello Kiera,


Since you have 3 categories you will have 3 ODFs when you run ComparativeMarkerSelection. In the phenotype test parameter you can choose either one versus all (which is the one you have selected in the job you ran) or all pairs (where you'd see the results of comparing. If you want only one ODF file, you'd need to provide a CLS file which classifies your data into only 2 classes (though, I think that is a different scientific question than what you originally set out to ask).


With regards to the p-values, the ODF files on job #279801 have a column named Feature P, that is the p-value for that specific gene (https://www.genepattern.org/modules/docs/ComparativeMarkerSelection/10). let us know if you have more questions!


Edwin.
