Oh, I see the issue. The Transcriptome Database parameter is flagged as a required field even though it is not used for RSEM produced datasets. We’ll get this corrected.

In the meantime, if you know what transcriptome you data was quantified with, you can supply the GTF file in .tar.gz format and it’ll allow you to run the dataset even though the file itself will be ignored in the analysis.

If you don’t know which transcriptome was used, let me know (along with the species of the data) and I can direct you to a file that can be used.
