Hi,


when you see a result or error, you should always read the stdout and stderr files that are returned as they will usually give a good idea of the cause.  In this case, the contents of the file, remote_stdout.txt, contains the following;


        GISTIC version 2.0.23
 
        GISTIC 2.0 input error detected:
        All input data were removed after NaN processing.


Hope this helps,
