Hello Sara,

The old GenePattern R package was deprecated and removed because it no longer works with recent versions of R.


That said, you should still be able to access GenePattern modules and launch GenePattern jobs using the GenePattern REST API. Unfortunately it's a bit more work, but from R you can load the httr and jsonlite packages, then call the endpoints described in the GenePattern REST API documentation.

https://www.genepattern.org/rest-api

If you're familiar with Python, we also have a Python library that is available.

https://github.com/genepattern/genepattern-python


Thorin Tabor
GenePattern Team
