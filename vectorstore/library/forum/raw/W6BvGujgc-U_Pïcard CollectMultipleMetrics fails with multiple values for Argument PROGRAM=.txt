You need to select the 'prefix when specified' option for your
parameter. You can do this in the Edit module GUI or by editing these
lines in your manifest file,
p4_prefix=PROGRAM\=
p4_prefix_when_specified=PROGRAM\=


FYI, here's the full example from a manifest file for the 'p4_' param ...
p4_MODE=
p4_TYPE=TEXT
p4_default_value=
p4_description=Set of metrics programs to apply during the pass through

the SAM file. Default value: [CollectAlignmentSummaryMetrics,

CollectBaseDistribut\
ionByCycle, CollectInsertSizeMetrics, MeanQualityByCycle,
QualityScoreDistribution]. This option may be specified 0 or more times.

This option can be set \
to 'null' to clear the default list.

p4_fileFormat=
p4_flag=PROGRAM\=
p4_listMode=cmd_opt
p4_name=PROGRAM
p4_numValues=0+
p4_optional=
p4_prefix=PROGRAM\=
p4_prefix_when_specified=PROGRAM\=
p4_type=java.lang.String
p4_value=\=none (use picard default);\
CollectAlignmentSummaryMetrics\=CollectAlignmentSummaryMetrics;\
CollectInsertSizeMetrics\=CollectInsertSizeMetrics;\
QualityScoreDistribution\=QualityScoreDistribution;\
MeanQualityByCycle\=MeanQualityByCycle;\
CollectBaseDistributionByCycle\=CollectBaseDistributionByCycle;\
CollectGcBiasMetrics\=CollectGcBiasMetrics;\
RnaSeqMetrics\=RnaSeqMetrics;\
CollectSequencingArtifactMetrics\=CollectSequencingArtifactMetrics;\
CollectQualityYieldMetrics\=CollectQualityYieldMetrics;\
null\=null (overrides default)

Copying this reply to a related question into this thread ...


When you create a 'Get-opt style list' for a parameter, they are passed along to the command line in the order in which they are selected. 


To workaround this problem ...
1) open the menu and click 'X Uncheck all'
2) select 'null' option
3) select other options in order ...


I expect the selections to appear in the order in which they were made in the GUI, e.g.
PROGRAM	

null (overrides default), CollectAlignmentSummaryMetrics, CollectInsertSizeMetrics
Which should result in a properly ordered command line, e.g.
  java -jar /path/to/picard.jar CollectMultipleMetrics ... PROGRAM=null PROGRAM=CollectAlignmentSummaryMetrics PROGRAM=CollectInsertSizeMetrics  ...

to GenePattern Help Forum
When experimenting with this, I discovered a bug with the way GenePattern handles 'Get-opt style list' text parameters. The default empty string value is incorrectly added to the command line as: "[]". E.g.
  java -jar /path/to/picard.jar CollectMultipleMetrics I=/path/to/file.bam []


Instead of
  java -jar /path/to/picard.jar CollectMultipleMetrics I=/path/to/file.bam


As a workaround (pending a bug fix in GP v3.9.11), I suggest changing your module to include each PROGRAM arg as an individual optional parameter. I am attaching the 'Demo.Picard.CollectMultipleMetrics_v0.4.1' module which is organized this way. To make it a bit more readable I created a 'paramgroups.json' file which groups all of the PROGRAM args into one section.


You can start with a copy of this module. Don't forget to make some edits to the manifest before adding to your server.
change the lsid to match the baselsid of your server; increment or set the version as you see fit.
set the author/organization
Additional edits are required. They can be done in the gui or in the manifest file.

remove 'echo' as the first arg of the command line; or keep it until you are satisfied
set the correct substitution for the picard.jar file. When testing locally I included the jar file in the module. I removed it from the zip to reduce the size of the attachment.
Here are the steps to build this from scratch in the GUI. 
Create a 'use.default' parameter.
  Name: use.default
  Select 'Make this parameter optional.'
  Flag: 'PROGRAM='
  Select 'prefix when specified'
  Create a drop-down list with two values
Value="" (empty), Display Value="default", select this as the default selection

Value="null"
Create a PROGRAM=program-name for each optional program-name arg. For example,
  Name: CollectAlignmentSummaryMetrics
  Select 'Make this parameter optional.'
  Flag: 'PROGRAM='
  Select 'prefix when specified'
  Create a drop-down list with two values
Value="" (empty), Display Value="no", select this as the default selection
Value="CollectAlignmentSummaryMetrics"


For convenience, here are the relevant sections of the manifest file  


commandLine=echo <java-1.8> <java_flags> -jar <libdir>picard-2.10.6.jar CollectMultipleMetrics \
    <input.file> \
    <fasta.reference> \
    <output.prefix> \
    <use.default> \
    <CollectAlignmentSummaryMetrics> \
    <CollectInsertSizeMetrics> \
    <QualityScoreDistribution> \
    <MeanQualityByCycle> \
    <CollectBaseDistributionByCycle> \
    <CollectGcBiasMetrics> \
    <RnaSeqMetrics> \
    <CollectSequencingArtifactMetrics> \
    <CollectQualityYieldMetrics>


Note: commandLine can be split with the '\' character


The 'use.default' parameter can toggle between (no arg) and 'PROGRAM=null'.
p4_name=use.default
p4_MODE=
p4_TYPE=TEXT
p4_default_value=
p4_description=Default value\: [CollectAlignmentSummaryMetrics, CollectBaseDistributionByCycle, CollectInsertSizeMetrics, MeanQualityByCycle, QualityScoreDistribution]. This option can be set to 'null' to clear the default value.
p4_fileFormat=
p4_flag=PROGRAM\=
p4_numValues=0..1

p4_optional=on
p4_prefix=PROGRAM\=
p4_prefix_when_specified=PROGRAM\=
p4_type=java.lang.String

p4_value=\=default;null\=null


Each additional 'PROGRAM=' arg is a separate parameter.
p5_MODE=
p5_TYPE=TEXT
p5_default_value=
p5_description=
p5_fileFormat=
p5_flag=PROGRAM\=
p5_name=CollectAlignmentSummaryMetrics
p5_numValues=0..1
p5_optional=on
p5_prefix=PROGRAM\=
p5_prefix_when_specified=PROGRAM\=
p5_type=java.lang.String
p5_value=\=no;CollectAlignmentSummaryMetrics\=CollectAlignmentSummaryMetrics




The 'paramgroups.json' file requires manually editing and adding to the zip file. E.g.
zip -r _modulename_v_version.zip paramgroups.json
paramgroups.json
[
{       name: "Basic Parameters",
  parameters: [ "input.file", "fasta.reference", "output.prefix" ],
      hidden: false
},
{       name: "PROGRAM args",
 description: "Set 'PROGRAM=' args to apply during the pass through the SAM file. This option can be set to 'null' to clear the default value. This option may be specified 0 or more times.",
  parameters: [
     "use.default",
     "CollectAlignmentSummaryMetrics",
     "CollectInsertSizeMetrics",
     "QualityScoreDistribution",
     "MeanQualityByCycle",
     "CollectBaseDistributionByCycle",
     "CollectGcBiasMetrics",
     "RnaSeqMetrics",
     "CollectSequencingArtifactMetrics",
     "CollectQualityYieldMetrics"
   ],
      hidden: false
}
]
