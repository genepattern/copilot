Hi!


I'm trying to put together parts of the now defunct Affymetrix SNP6 Copy Number Inference Pipeline (https://www.genepattern.org/affymetrix-snp6-copy-number-inference-pipeline#gsc.tab=0) to do copy number analysis on SNP6 microarray data, and I had a couple of questions relating to accessibility and implementation of some of the modules.


The first few steps of the pipeline are as follows: SNPFileCreator (to take CEL files and normalize intensity values within batches) -> Birdseed (to define what genotypes of normal data look like to be used as calibration) -> CopyNumberInference (determine copy number from sample data based on calibration from normals). Birdseed and CopyNumberInference no longer appear to be publicly available on GenePattern, though I have found an implementation of Birdseed that I can use locally. I'd thus like to find a way to string together the different modules (SNPFileCreator + Birdseed + CopyNumberInference) between what's still available on GenePattern and what I can implement locally. My questions are as follows:


1) The SNPFileCreator module has a functioning implementation on GenePattern. Is there any way to download this module so that I can use it locally and feed the output directly to my local implementation of Birdseed?
2) Is there any record of the CopyNumberInference module? Even if it is no longer implementable on GenePattern, is there any of the source code that I could download and try to adapt?


Thank you!
Best,
Nicolas

Hi Nicolas,


You can get the executable for the SNPFileCreator by going to cloud.genepattern.org, selecting the SNPFileCreator module, and choosing Export from the gear menu on the upper right hand side. That will export a zip file that contains the Java code for the analysis. Please note that there is a separate module, SNPFileCreator_SNP6, for the SNP6 chip, in case that chip was used. We are working on retrieving the code for CopyNumberInference and will let you know as soon as we have it. 


Best,
Michael
