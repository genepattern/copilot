Hello Mikayla,


If you want to install that package, you can open a new terminal similarly as you would create a new Notebook: under the Files tab, click new, select Terminal from the list.


There you can do a install that package for your user with pip, the command you'd need to run is:


pip install --user mygene



Don't forget to add the "--user" flag to explicitly tell pip to install that package locally. If you forget to add that flag, you may experience some inconsistent behavior.


Make sure you restart the kernel of the notebook in which you are trying to import mygene before trying to import that package again.
