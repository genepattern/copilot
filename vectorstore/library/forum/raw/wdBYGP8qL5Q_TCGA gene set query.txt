Hi Daniel,


Sorry for the late reply, I thought I posted the message but I guess it didn't send. 


To answer your question, the TCGAImporter module will help with that. This module imports data from TCGA by taking in a GDC manifest file, downloading the files listed on that manifest, renaming them to be human-friendly, and compiling them into a GCT file to be computer-friendly. 


Some documentation links:
Module documentation: https://www.genepattern.org/modules/docs/TCGAImporter/6#gsc.tab=0
Guide to downloading manifest file: https://github.com/genepattern/TCGAImporter/blob/master/how_to_download_a_manifest_and_metadata.pdf


Hope this helps, 
Edwin
