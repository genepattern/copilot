Hello, 


Thank you for bringing this to our attention. The recent browser security updates have sealed up a potential security hole in passing content to/from https and http domains  (IE secure & unsecure). While this is ultimately a good thing, it has caused some trouble out in the wild, such as this bug you've encountered. Basically, the browser is not allowing a required file to be accessed, so the viewer can not finish displaying your data.


I've notified the current developer of this module, and we will let you know as soon as this issue has been resolved.


All the best
