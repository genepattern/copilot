Felix,


A couple of things are going on here.  First the reported queue of 6022 jobs is incorrect.  There has been a fix made but not deployed to prod as of yet.  The real number is 6 (the error is it includes a log of failed jobs in the count going back to 2018 when the AWS server went live).


Second, some modules are run on the SDSC Expanse supercomputer instead of on AWS (to save money so we can keep providing this free service).  These include GISTIC, SubMap, NearestTemplatePrediction and a few others.  At the moment there is a backlog on Expanse, but 4/6 GenePattern jobs have started running with the other 2 still pending.


Hopefully your jobs will start to run soon too.


Thanks for your patience


Ted
