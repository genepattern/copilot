Hello Katie,

The issue is fixed again.

To fill you in on what's causing the issue, it looks like something you are running is creating a .ipython directory in your account and installing stuff there. When your Jupyter server is started back up, it tries to read Python packages in that directory, but it runs into something that causes it to throw an error. This prevents Jupyter from starting back up and thus you get a 500 error.

I'm still diagnosing exactly what in the .ipython directory is the problem, but in the meantime I've renamed ".ipython" to "ipython" and you should be able to log in.
