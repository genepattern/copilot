Hi


with the current Gistic 2.0 module you cannot upload the reference file.  There are a few ways you could possibly get around this;
1- Run your own GenePattern server, edit the module to let you pass in this file instead of taking it from the list
2- If you own Matlab, you could run the non-GenePattern gistic in Matlab
3- If you can wait until next week I could help by temporarily adding your mat file to the module or making an altered version as in #1 above.


Hope this helps,
