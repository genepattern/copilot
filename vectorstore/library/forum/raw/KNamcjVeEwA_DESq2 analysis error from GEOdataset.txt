Janet,


your cls file now has extra newline characters after every line.  The blank lines in between prevent the modules from reading it correctly.  I deleted those and tried a DESeq2 run and came up with a different error;

      The cls.file must be categorical with exactly two classes


So it seems for DESeq2 you will need to filter your dataset to do pairwise comparisons or one-versus-all for the conditions of interest.  The DESeq2 documentation (https://genepattern.github.io/DESeq2/v1/index.html) states for the cls.file parameter definition;


A categorical CLS file specifying the phenotype classes for the samples in the GCT file. This should contain exactly two classes with the control specified first.
I suggest that you start a new thread in the forum if you want help with DESeq2 as it will be a different question than the file format issues that we have been chasing in this thread, and also it will require someone other than me who is more familiar with DESeq2 to be able to help with how to do your analysis.


hope this helps,


Ted
