The GISTIC GenePattern module is released as a linux only binary. It will not run on a Windows computer. For best results I suggest running it on one of our publicly available servers.

For more information on running GISTIC as a standalone application:
    http://portals.broadinstitute.org/cgi-bin/cancer/publications/pub_paper.cgi?mode=view&paper_id=216&p=t
    ftp://ftp.broadinstitute.org/pub/GISTIC2.0/INSTALL.txt

The installer appears to be linux only.

Regards,
Peter
