Hello Thomas, 


The war file link is below.
However - please note that you've now officially entered DIY territory, and are truly administering your own Franken-GenePattern*.
You will need to:
 install Mac OS X and reverse-engineer the project layout for your server.
 caveat: GP *must* use the '/gp' servlet path, e.g. this will work 'http://127.0.0.1:8080/gp'. This will not: http://127.0.0.1:8080/my-custom-path'
   * caveat: we have not ever tested GP on a different version of Tomcat



We'll help if we can, but if you can use the typical Mac installer, or better yet one of our hosted servers, that will free you from server administration tasks and allow you to simply use GenePattern and its modules.


http://software.broadinstitute.org/cancer/software/genepattern/download_installer/installers/gp-3.9.10-156_deprecated/warfile/gp_war.zip



Good Luck!
-Barbara
