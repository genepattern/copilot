Hello,

It looks like your Python package is being installed into the container's default Python environment rather than the Python environment used by that specific IPython kernel. To make your package available in the kernel, I recommend installing it with the --user flag. For example:

!pip install --user py4cytoscape

Hope that helps.

OK ... I think I'm OK now ...


For the record, too ... I needed to make sure the module was installed in the directory corresponding to the kernel I was using. For example, py4cytoscape was installed in the local directory for python3.8 ... a new script that uses python3.7 didn't find py4cytoscape. The fix was to set the kernel for the new script to python3.8, too.


Hopefully, anyone else having this problem will see this thread.
