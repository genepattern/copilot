Within GenePattern, if a module (ssGSEA in this case) logs anything to stdout, it will be captured and returned in a file called stdout.txt.  The same thing happens with any logging to stderr being captured and placed in a file called stderr.txt.  For your ssGSEA run it appears that the stdout.txt is just logging the overlap between each gene set and the input data.

Hi Jaishree,


To follow up Ted's answer, the results in the .PROJ.gct file are the enrichment scores of those gene sets within each sample in your input file. ssGSEA computes enrichment at both the top (positive scores) and bottom (negative scores) of the input expression data.
