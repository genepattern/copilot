Hi


in the description for the "mutation type dictionary" parameter, it says


        "The mutation type dictionary to use for automatic category and effect discovery. This is necessary only if you are using a MAF file without the columns "categ" and "effect"."



it seems that neither of your maf files has these columns so you probably need to provide the dictionary files you used for annotation (which you named above) to that parameter.
