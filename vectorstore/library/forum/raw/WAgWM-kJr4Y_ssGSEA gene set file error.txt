Error in vector(length = gene.set.size, mode = "character") : invalid 'length' argument Calls: ssGSEA.cmdline Execution halted



The job number is 424483.


I have successfully run ssGSEA with the same input file using GenePattern's dropdown menu of gene set files (see job 424404) which removes the input file as the issue. 


Have you seen this error before and could you provide any insight on why the manually generated gene set file is causing the error?

Hi Sara,


I haven't the foggiest idea how something like this might have happened, but there appears to have been one single non-UTF8 linebreak at the "TURASHVILI_BREAST_LOBULAR_CARCINOMA_VS_LOBULAR_NORMAL_DN" set. I replaced this line break with the correct type and the file seems to be working now. I've attached the corrected GMT to this reply. Let me know if you have any additional issues.
