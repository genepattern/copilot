Hi,


Also note that the ConstellationMap documentation recommends using the combine.off mode in the upstream ssGSEA job, otherwise it will create new combined gene sets for any _UP / _DN (up- and down-regulated) paired gene sets, which will not be represented in the original GMT file.  The workaround would be to create your own GMT file with the combined gene sets included, but the docs recommend just using combine.off instead.
