Hi Alkaid,


That is indeed the same issue. This gct file is not a gct file which expects tab delimited text formatted to the GCT specification. This file appears to be an XML formatted file saved from Microsoft Excel as an XLS/x spec format. The file would need to be reopened in Excel, and saved using the "Save As > Text (tab delimited)" function, then have the file extension changed from .txt to .gct.


Hope that helps,



-Anthony
