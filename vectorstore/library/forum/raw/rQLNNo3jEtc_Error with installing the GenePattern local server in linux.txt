Try a headless install instead. For a headless install, place install-gp.properties file next to the GPserver.bin file. (ftp://gpftp.broadinstitute.org/install-gp.properties)
Edit the file, so that the correct values set.
Install with this command:
    ./GPserver.bin -f install-gp.properties
