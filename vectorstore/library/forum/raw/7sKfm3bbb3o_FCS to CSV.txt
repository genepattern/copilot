Hi


the problem appears to be the double spaces between the "Ph" and the "f" right at the start of the input filename,  and the logic that uses the base of the input filename for the output files is not working properly for that.


There are two quick workarounds;
1. Edit the input file name to remove the double spaces (ideally all spaces to be safe) and then re-run.
or
2. Change the value for the parameters "Output CSV file name" and "Output keyword file name" to not use the <Input.FCS.data.file_basename> placeholder.


Please let me know if this works for you


Ted
