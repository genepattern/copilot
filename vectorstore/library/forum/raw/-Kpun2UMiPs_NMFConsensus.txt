Elena,


Although the outputs of NMFConsensus do not provide this information directly, it is possible to visualize them using other tools. One approach you can take is to:
- Take the membership.gct file corresponding to the clustering in which you are interested, identify which samples belong to which cluster
- Use that information to run SelectFeaturesColumns providing the original expression (gct) file you provided to NMFConsensus 
--> With SelectFeaturesColumns you will be able to choose a subset of columns, repeat this process for your clusters of interest and you will have a GCT file for each cluster
- Visualize each cluster using HeatMapViewer


We recognize this process can be time consuming, we are planning on providing a more streamlined way to visualize the expression patterns on each cluster (but I can't promise that this pipeline/notebook will be ready right away).


Are you comfortable with programing? If so, you could replicate this workflow with your programming environment of choice as well (of course we'd recommend using GenePattern Notebooks for that).
