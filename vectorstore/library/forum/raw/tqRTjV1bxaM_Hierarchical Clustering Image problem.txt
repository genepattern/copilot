Meg


thanks for the re-run.  The problem appears to be that there is an extra blank line between the header line and the line with the EWEIGHT values in the cdt file (i.e.line #2).  HierarchicalClusteringViewer handles this OK, but the HierarchicalClusteringImage module expects another line of data.  You can generate the image using HierarchicalClusteringImage if you delete that line from the file.


Can you tell me what was used to generate these clustering results?  We just pulled HierarchicalClustering version 7.17 from the server because it has a few bugs.  This was not one of the known bugs but if you did use this version to generate the clusters, then you can try re-clustering using version 6 (was previous, now the latest version) to see if that fixes the problem.


Hope this helps,


Ted
