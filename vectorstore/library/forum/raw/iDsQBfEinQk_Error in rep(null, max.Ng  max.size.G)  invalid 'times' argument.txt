Hi Catarina,


It looks like the gene set file you provided was an excel file that was simply renamed to .gmt. In order for ssGSEA to be able to parse the file it needs to be saved out of excel as tab delimited text (.txt), and only then renamed to the .gmt file extension. Once you've corrected the file format your job should run successfully, but let us know if you still encounter errors
