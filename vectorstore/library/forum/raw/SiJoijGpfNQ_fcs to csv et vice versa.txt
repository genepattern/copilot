Hello Vince, 


Yes, you can convert fcs to csv with GenePattern. There are two modules - FcsToCsv and CsvToFcs - with rather self-explanatory names.


The easiest way to use them is actually to just create an account on our hosted server and just run your jobs. This saves you from installing and maintaining your own GenePattern server (we do all that work in the AWS Cloud for you!).


If you need to install your own server for security or privacy reasons...etc You can find information about that in our GitHub repository. 


We do not currently support Windows as a local install. However, we are actively working on GenePattern in Docker (IE running in a Docker container) which will allow Windows users to once again have local GenePattern installs if they so choose. Stay tuned!


Please let me know if I can help with anything else.


Best
-Barbara
