Guy,


i would not expect the Broad's smtp server to work for you, but I presume your institution does have a mail server that accepts the smtp protocol, and that you would set the javax.mail.session.properties in your genepattern config files to point to that one with the appropriate address, port and authentication.  Our production server on AWS uses mailjet as its smtp server at this time.  I believe you need to create your own account there if you wish to use it too but it has a free option https://www.mailjet.com/pricing/ for up to 6000 emails per month (I think that is what we are using).  Below is our exact configuration (except for the username/password) for mailjet


 ## Mailjet smtp server configuration
    smtp.server: "in-v3.mailjet.com"
    smtp.auth.username: "our mailjet username"
    smtp.auth.password: "our mailjet password"
    smtp.from.email: "gp-...@broadinstitute.org"
    #
    # additional mail.properties
    #
    "javax.mail.Session.properties": {
        #"mail.host":       "in-v3.mailjet.com",
        #"mail.smtp.host":  "in-v3.mailjet.com",
        #"mail.smtp.port":  "587",
        #"mail.debug.auth": "true",
        #"mail.smtp.auth", "true",
        #"mail.smtp.starttls.enable": "true"
        # "mail.smtp.localhost": "",
    }


I am not understanding your question "And what about the possibilty to use the HSQL database directly ?".  I do not believe the database can send email or if it can I have never looked into it.  Could you clarify what you are asking?

I finally managed to  fix the issue. For the benefit of whoever is reading this : I put in the file config_custom.yaml :
smtp.server: <a server accessible from our computer>

Guy


as an administrator you will have access to a page at <genepatternserver>/gp/sql.jsp that allows you to perform arbitrary SQL commands against the database.  You can use this to change a users email (update gp_user set email='new email address' where user_id = 'username') or to delete a user if you choose (delete from gp_user where user_id='username').


I don't think its possible to do anything about the password directly due to the way the encryption is set up, but after resetting an email you can use the forgot password link to handle it.


Hope this helps


Ted
