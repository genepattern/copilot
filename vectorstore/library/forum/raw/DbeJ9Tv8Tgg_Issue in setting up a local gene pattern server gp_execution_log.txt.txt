The 'gp_execution_log.txt' file is hidden by default. To see it, you must select the "Show Execution Logs" checkbox at the top of the job status page for your job.

I am not sure what is causing the particular error with PARIS. Most likely you need to configure your server to ignore stderr output. To do so, edit the config_custom.yaml file. Make sure it has these settings in the default.properties section.

default.properties:

    ...

    # Error handling
    #  by default, non-zero exit code is an ERROR
    job.error_status.exit_value: true
    #  by default, ignore stderr output
    job.error_status.stderr: false

    ...

If you are not familiar with config_custom.yaml, follow these steps.

To get started, create a new config_custom.yaml file as a copy of the config_default.yaml. E.g.
  cd <GenePatternServer>/resources
  cp config_default.yaml config_custom.yaml
The GenePattern Server, will use the custom file instead of the default file so it's important to start with the existing copy.

After each edit to the config_custom.yaml, you must reload the config from the admin page.
  Administration > Server Settings > Job Configuration
  click Reload job configuration
