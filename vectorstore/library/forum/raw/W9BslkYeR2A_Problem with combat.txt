Your GCT file is full of duplicate row names.


For instance, the row name in row 9, occurs 10x within the GCT file.


As the error states, this is not allowed. GCT files must have unique row identifiers. 


Please read the documentation for additional requirements. Note that, for instance, you need to preprocess this data before sending it through ComBat.
http://software.broadinstitute.org/cancer/software/genepattern/modules/docs/ComBat/3


Please let us know if you have any questions.
