Hi,


I think the problem is probably the spaces in your sample names.  If you look at the SubMap documentation (https://cloud.genepattern.org/gp/module/doc/urn:lsid:broad.mit.edu:cancer.software.genepattern.module.analysis:00101:4), for both the datasets it says


      "Note: Remove spaces from sample names"


Since the error seems to be a column count issue, I suspect its treating the space separated parts of the sample names as separate columns and this is throwing off the count (plus if it made it further it would probably try to read the latter name fragments as numbers and generate a different error).


Hope this helps

Kishibe,


There were other issues with the gct file formats.
- There was an extra header line (starts with X1.ncol.SubMapExp.)
- it was defined as gct version 1.3 but SubMap accepts 1.2
- On the 2nd line it had two extra values (e.g. 2419 58 1 1).  This might be because of version 1.3 of the format?  I am not familiar with that version as it is not used anywhere in GenePattern AFAIK but was used in some other software.


When I corrected those points I was able to get a successful run

Hi Ted,


Thanks for pointing out these issues, and I also successfully ran the module and got the result. The crux for the matter does exist in the gct version. GCT version 1.2 avoided all the previous errors.


The input files were created in R. Briefly, the gene expression matrix (df, with sample names in columns and gene symbols in rows) was converted into a GCT class and wrote to the disk:


library(cmapR)

SubMapExp = new("GCT", mat = df)
write_gct(SubMapExp, ofile = "SubMapExp", ver = 2)    # ver = 2 here resulted in a GCT version 1.2 file, and the failure to provide this parameter was the direct reason of the previous error


The 3rd line of the .cls file was wrote to the disk, and the 1st and 2nd lines were manually added to it:


SubMapCluster = data.frame(Cluster = ifelse(Metadata$Status == 'Del', 1, 0)) %>% t()                                 # I have two group named 'Del' and 'WT'

write.table(SubMapCluster, file = 'SubMapCluster.cls', quote = F, row.names = F, col.names = F, sep = ' ') # the sep here is a space

 
Thanks again for your help!
