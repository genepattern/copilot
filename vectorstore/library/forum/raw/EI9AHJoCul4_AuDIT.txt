Sadly, the generic R2.5 image didn't fix it. The module runs without error but also doesn't generate any output. I did a quick pass of debugging, but that didn't turn anything up. All of the R code seems to be executed, but again, no output.


I suspect that there may be an issue whereby the output is being cleaned up with the container, but I'm not sure.


So, at this point. I would suggest debugging in a local R2.5 container and or local GenePattern server.
