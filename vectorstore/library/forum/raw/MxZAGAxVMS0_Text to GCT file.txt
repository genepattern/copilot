Hello,

 

It looks like your operating system is hiding known file extensions by default. You'll have to set file extensions to "show" then you should be able to remove the previous .txt extension.

Microsoft describes how to do this here: https://social.technet.microsoft.com/wiki/contents/articles/1784.windows-how-to-view-file-name-extensions.aspx
