HI Roberto,

 

This is a bit of a weird one, simple fix though, in your gene set description you have a “–“ character, this character looks like a dash but appears to be some auto-formatting replacement (likely a “long dash”). For whatever reason the gene set database parser in ssGSEA is choking on this character, remove them from the gene set descriptions or replace them with a standard short dash in a plain text editor and the gene sets should work just fine.

 

I’ll look into if we can implement a fix here but it might be a programming language problem.
