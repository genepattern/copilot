Hi


I think this is the same problem as in https://groups.google.com/forum/#!topic/genepattern-help/dsPt8dynvw0.  Basically the AWS compute node at the head of the cluster we use to run jobs had a problem and was failing all jobs for a while.  Since it failed immediately the cluster saw it as unused and it would then get the next job and so on blocking anything from running.  This should now be fixed so try reloading and re-running your analysis.


Hope this helps


Ted
