You can’t pass a special character through to the command line. Furthermore, it's tricky to handle quote, space and other special characters in the GenePattern manifest file format. 


The drop-down menu selection is passed as a string to the module command line. You can use '\' as an escape character.  Note: the characters '=' and ';' are not allowed in the module integrator (GenePattern GUI). For your drop-down menu, I suggest one of three encodings:
* escape sequence, e.g. '\n', '\t'
* unicode, e.g. 'U+000A', 'U+0009'
* unicode escape sequence, e.g. '\u000A', '\u0009'


From the GenePattern module integrator I created an example 'delim' parameter with '\t', '\n', and ' ' as options. Here's the manifest file format for that param. 
p2_TYPE=TEXT
p2_default_value=\\t
p2_description=Example drop-down options for tab, comma, or space as a delimiter
p2_fileFormat=
p2_flag=-s
p2_name=delim
p2_numValues=0..1
p2_optional=
p2_prefix=-s
p2_prefix_when_specified=-s
p2_type=java.lang.String
p2_value=\\t\=tab;,\=comma; \=space






Some technical details:
* the characters '=' and ';' are not allowed in the module integrator (GenePattern GUI)

* the manifest is in java .properties format, see https://en.wikipedia.org/wiki/.properties 
* the job engine will pass an array of args to the command line; it's up to your module to parse the args correctly. It is preferable to avoid complex character escape sequences.

* wikipedia List_of_Unicode_characters
* see FileFormat.info for more details on the the unicode format
