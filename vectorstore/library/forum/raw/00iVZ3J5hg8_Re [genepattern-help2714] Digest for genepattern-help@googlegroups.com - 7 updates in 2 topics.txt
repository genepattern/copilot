Ted Liefeld <lie...@broadinstitute.org>: Jun 13 11:33AM -0700

Hi, one of my coworkers noticed another problem that also needs to be
addressed. The output filename specified contains the characters "<" and
">". This is probably the true cause of the failure. In my tests using
different memory settings, some included that and some did not which lead
me to mistakenly identify memory as the problem.
 
So please rerun with the "<" and ">" removed from the output file name and
let us know how it goes.
 
Ted
 
p.s. the reason for the issue with the characters is that GenePattern
tokenizes and replaces elements on the command line that are between the <
and > characters. You can see more details in the GenePattern Programmers
Guide (https://www.genepattern.org/programmers-guide#_Creating_Modules)
about 1/4 of the way down in the section on the command line.
