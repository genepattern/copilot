Hi,


this version of GSEA and  the data store at the Broad institute seem to be slightly out of sync.  The chip file URL that is in the GSEA parameter is wrong, missing a single character.  You can use this link for the moment;



https://data.broadinstitute.org/gsea-msigdb/msigdb/annotations/human/Human_Ensembl_Gene_ID_MSigDB.v2024.1.Hs.chip

Note the "v" 14 characters before the end of the URL.  It is missing in the parameter definition.  This looks like something the GSEA team can fix easily without a new module version.  i will contact them immediately, in the meantime try using the link with the 'v'.
