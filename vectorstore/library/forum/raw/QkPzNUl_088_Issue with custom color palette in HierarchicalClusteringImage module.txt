Hi Sara,

 

It looks like there was an issue with the color codes used in the palette. The color codes need to be a hex value but these all had a trailing "FF" value making them octets, probably an alpha (transparency) code that the module wasn't accepting. I was able to confirm that stripping those values out allows the module to plot with this palette and that it will plot with the expected inferno color space. I've attached the fixed palette here.
