How do you know from a odf file (results of SOM determination) which row belongs to which cluster?



===================================================================
Best Answer




You need to look at two lines in the odf output file:
- The line that begins with "ROW_NAMES"
- The line that begins with "assignments:"

The values in the "assignments" line correspond to which cluster each row is assigned to. Clusters are numbered beginning with 0.

To match each row with its cluster, look at the contents of the line that begins with "ROW_NAMES". The first value on the ROW_NAMES line is assigned to the first cluster number on the "assignments" line, and so on.
