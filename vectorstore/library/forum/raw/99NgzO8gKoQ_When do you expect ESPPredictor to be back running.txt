Hello, 


The command line for ESPPredictor in GenePattern is:
<java> <java_flags> -cp <libdir>gp-modules.jar -Dmatlab\=/broad/software/nonfree/Linux/redhat_5_x86_64/pkgs/matlab_2010a/bin/matlab org.genepattern.module.ESPPredictor <libdir> peptideFeatureSet <input.file> zzz <R2.5_HOME> <libdir>ESP_Predictor.R Predict PeptideFeatureSet.csv <libdir>ESP_Predictor_Model_020708.RData <libdir>


<xxx> is a variable - https://launchschool.com/books/ruby/read/variables


This is like sending email to a mailing list, where the TO:  field has a placeholder like <email> and this is populated by a computer program, when you send, with the email of someone on your mailing list, so that you don't have to type in each email.


Basically, this means you need to replace each of those < > instances with the "hardcoded" value for your computer.  something like:


(you'll want to make sure to add java to your path https://www.java.com/en/download/help/path.xml)


then from the director where the gp-modules.jar file is (where you extracted the module .zip file)


java -cp <libdir>gp-modules.jar -Dmatlab=C:\Program Files\MATLAB\R2010a org.genepattern.module.ESPPredictor peptideFeatureSet <input.file> zzz C:\Program Files\R\R-2.5.0\bin ESP_Predictor.R Predict PeptideFeatureSet.csv ESP_Predictor_Model_020708.RData


Both Peter and I are out next week, so if this doesn't work, we'll help you out when we get back. We're also going to create a new version of this module for our Amazon Cloud server, hopefully, to be made available in September.


Best
