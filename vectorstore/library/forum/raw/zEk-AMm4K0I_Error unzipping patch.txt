Hi


it appears you found a bug in our current version.  The issue is that the patch URL is being redirected several times (from software.broadinstitute.org -> www.broadinstitute.org -> modulerepository.genepattern.org -> https://modulerepository.genepattern.org) and somewhere along the way the code is getting confused and is not following the redirect.


As a temporary workaround, I have edited the module manifest to use the final path and made it available at https://datasets.genepattern.org/data/module_support_files/BowTie/Bowtie.aligner.patched.zip.  You can try to install it from this URL instead using the GenePattern "Modules & Pipelines --> Install from zip" menu item.


I have created a new bug report for this and we will fix it in a future GenePattern release.


hope this helps,


Ted
