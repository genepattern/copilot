Hi,

I am trying to use the Hierarchical Clustering module that is offered under the Featured Notebooks section. I have used both the RNA-Seq module (where you specify a class file as well as a GCT file in the beginning) and the non-RNA-Seq module. In both of these modules, after running the clustering algorithm for columns, we get a heatmap with the sample names that are not in the original order as the gct file (as expected since it was clustered). The problem is that when I import my class file into the HierarchicalClusteringViewer, the sample names do not correspond to the classification from the class file.

I created the class files with the ClassFileCreator v4 module based on my gct file that I used in the Hierarchical Clustering modules. In the Hierarchical Clustering modules, are the class files supposed to be linked to the gct file to obtain the proper assignment of classification to sample name?

I would assume that specifying the class file as well as the gct file in the beginning of the RNA-Seq module would link the two and would show the proper classifications in the HierarchicalClusteringViewer. However, the original class file that I input as a parameter does not show up automatically in the final heatmap, and I have to add it to the viewer, in which case it enters in the incorrect order. Is there any way to fix this problem (ie link the gct and class files together)?

Hi Anthony, 


That's a very good point - once you reorder for the clustering the resulting cdt file sample ordering no longer matches what was in the gct and thus the cls file.


Currently, you'll have to re-order or re-create the cls file by hand to match the cdt file order. Annoying, I know. If you want to try a programmatic(ish) approach, that might at least reduce the possibility of human error, you could try converting the cdt to a gct, then running ClsFileCreator on the resulting gct , then use that cls to label against the cdt in the viewer. Not attractive, but potentially an option. https://software.broadinstitute.org/cancer/software/genepattern/file-formats-guide#_Creating_Input_Files_CDT


I'm also talking with the dev team about what the effort would be to use the cdt file parsing from our HierarchicalClusteringViewer to allow us to create cls files from cdt files in ClsFileCreator.


I'll let you know what we decide. In the meantime, let me know how you get on.

-Barbara
