Hi Adam, there are two problems here.
First, from the error message you appear to be loading an XML file, which usually means an XLSX file. Input data for GSEAPreranked must be in a tab delimited text file.
Secondly, GSEA (both standard and Preranked) are intended to be run on the entire list of expressed genes (without applying fold change or pvalue cutoffs). A restricted list of 50 isn't a valid input dataset.

Hi Adam,

 

That is an error I don’t remember having encountered before, but it looks like its choking on the RNK file still, albeit in a different way. The only thing I can think of without seeing the file itself is that there may be a problem with the file extension that is preventing it from loading it in properly. The file extension should be .rnk (not .rnk.txt or something else) these will cause GSEA to be unable to identify the correct parser for the file.

 

If the extension is correct, you can send your input file to gsea...@broadinsitute.org (we’ll keep it confidential and only use it for debugging) and I can take a closer look and see if I can identify what’s causing the load to fail.
