Hello Chris,



This is a common GSEA error, the basic answer is:


"GSEA performs an initial filtering step where the list of symbols in the rnk (or other expression file) is considered the initial universe of "gene" expression, IDs in the gene set (eg gmt) file aren't considered for the gene set size cutoff. A reciprocal step is performed where symbols in the rnk file but not in the gmt file are also ignored. One of the most common causes of the error you've reported is when after performing this filtering step, there are fewer IDs remaining in the gmt file than the "min size" cutoff. This can also occur when the symbols in your gmt file aren't the exact same format as the symbols in your rnk file."


I pulled this from one of many threads in the GSEA help forum. If you need more information as to how to resolve the error for your data, I suggest you search there for the error message "none of the gene sets passed size thresholds", as there are many more specific responses in the forum from the current GSEA developer.


Please let us know if you have other GenePattern questions.
