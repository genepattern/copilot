Hi Stephane,


This is possible by listing all of the reference files as a single list in the module manifest file. We call this a static drop-down; as opposed to a dynamic one. You must create a new version of the module to change the list.


I am away from my work computer (and offline mostly) for the next week or so. I am happy to fill in the details when I get back.


Meanwhile, you can remind yourself of how to do this by creating a new module in GP. Add a file parameter with a static drop down. When you save and export the module to see the manifest file format.
Regards,
Peter
