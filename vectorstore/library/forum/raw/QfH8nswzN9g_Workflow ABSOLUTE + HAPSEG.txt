Hello,


Our module source for these is now archived in S3 Glacier and thus will take rather a long time to retrieve, and I'm not sure that the contents will be of use to you outside of an older version of GenePattern.

I suggest instead reviewing the Birdsuiite page here, which will also connect you with the original authors.

SNPFileCreator_SNP6 is a different module than SNPFileCreator and has some specific requirements to run. Please see this forum post for more information. That post does contain an FTP link which you won't be able to access in a modern browser. So I've put the module zip that it mentions in an archived repository in our GitHub organization.


I hope this helps.
Best
Barbara
