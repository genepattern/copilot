Roser,


there is something odd happening with ssGSEA to more users than just you.  Jobs being submitted with the default settings (2GB RAM in particular) are all failing this way.  Resubmitting the job requesting more memory (4GB) and the jobs seem to be running fine.  When the jobs are failing to start, they are unfortunately not producing any logs at all on the compute nodes.  So the jobs are dispatched and try to launch but fail.

My guess is that it is a memory issue either with the node, or else just the ssGSEA container requires a more powerful node to run on.  THere will be a brief interruption as I force a refresh of the current compute node collection for new VMs and I will also update the ssGSEA config to require 4GB of RAM.  Wait about an hour and then try resubmitting your jobs.  You WILL have to manually reset the memory if you reload a job since it will reload the lower (2GB) value.


Hope this helps
