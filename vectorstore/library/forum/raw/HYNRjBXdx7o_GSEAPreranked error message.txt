Hi Eleni,


"Essential container in task exited" is usually a result of the virtual machine GenePattern is using to run the job running out of memory. I'd suggest going down to the "Job Options" parameters and changing the default job memory from 2Gb to something more like 8Gb.


If you're still having issues after increasing the job memory please let us know
