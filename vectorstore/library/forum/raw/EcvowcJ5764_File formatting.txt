the file transfer error might not be the format.  There is a bug that is fixed in the next release of GenePattern. Can you tell me the username or email you used to register and I will try to check if that is the case and fix it.


The gct file format is OK but you have duplicate gene names (row names) and that will cause failures in most GenePattern modules.  I found it for "CYB561" but there might be others.  A quick test for this and format compatibility is to run it through the PreprocessDataset module as it is fast and validates the input format.
