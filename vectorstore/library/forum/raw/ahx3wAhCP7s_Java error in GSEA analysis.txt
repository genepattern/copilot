Have a closer look in the list of result files.  So long as you set the createZip parameter to 'true' (the default) there should be a ZIP file among them.


This is a behavior change from the previous version of the module to give users direct access to the GSEA reports without the need to download the file, unzip, and open the report.  The ZIP is primarily for use with GSEALeadingEdgeViewer, though obviously it can be downloaded as well.


BTW, there's a bug in this particular version of the module in the way the advanced parameters are displayed.  That will be fixed in the future.
