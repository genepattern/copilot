Swetha,


you can retry your job now and it should be able to go through, the problem was one of our compute nodes ran out of disk bit failed to shutdown.


Ted


Long version of what failed:


We dispatch jobs on AWS and they can share compute nodes.  Another user ran a job that consumed the entire disk (~170GB) but the process did not die, it just sat in a hung state.  The scheduler saw that the CPU on this node was 0% and so it kept dispatching jobs to this compute node, which then failed because there was not enough space to get the docker container or input files.
