Elena,


Seeing multiple genes/features with same p-values is not uncommon, particularly for the "extreme"  values (e.g., the ones with the highest scores, like the ones shown in the image you attached). Typically, if you were to increase the number of permutations run, you would expect the number of features with identical associated p-values. I believe the default number of permutation for ComparativeMarkerSelection is 10000, so if you want to get more accuracy on those estimated p-values you could try with a larger number of permutations. However, if you are already using a large number of permutations (e.g., the default 10000), I would focus instead on the combination of statistics that are being shown, like it sounds like you are already doing (e.g., low FDR and low p-value).


In short, this kind of p-value in "chunks" is indeed common to see, based on my experience.


Edwin.
