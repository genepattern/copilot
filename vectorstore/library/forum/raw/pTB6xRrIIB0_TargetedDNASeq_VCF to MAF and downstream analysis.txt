Hi Ravi,

1 & 3 - Given the type of analysis you are looking to perform the closest module on GenePattern seems to be MutSigCV (https://www.genepattern.org/modules/docs/MutSigCV). Take a look at the documentation to see if it fits your needs.

2 - For converting a VCF file to the MAF file format, there is no module currently on GenePattern that can do that task. Outside of GenePattern, you can check out this commonly used tool: https://github.com/mskcc/vcf2maf.

Let me know if you have any more questions of if we can help in any other way.

Thanks,
