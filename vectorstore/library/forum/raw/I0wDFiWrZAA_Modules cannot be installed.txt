Hello Bérengère


We no longer support Windows local GenePattern installs, and there has been a change to the way the servers connect to the repositories since we we did support Windows. Which is to say, this is expected.


Is there a reason you need a local install of GenePattern? There are a few DIY things you could try, but if you don't really need to be administrating your own server, I would suggest using on of our public servers: http://software.broadinstitute.org/cancer/software/genepattern/use-genepattern


Let us know how we can help.
