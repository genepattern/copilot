so it appears that the problem was there was insufficient memory (16GB) assigned to the job.  The silent failure is something we will have to look into on our server and seems to be a new failure mode specific to compiled matlab modules running in docker on AWS Batch.  After some experimentation I found that with your dataset it requires at least 64GB to get the run started.  That said its been running now for over 18 hours and I can only presume its not caught in a dead-end loop.  I am not familiar with MutSigCV or what a typical runtime should be but the 2.7GB input file is quite large so its not surprising that it is taking a long time.
