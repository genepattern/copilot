Hi Shang-Yin,

 

Desktop GSEA uses a slightly looser definition of the CLS file specification than GenePattern does, so a small change will need to be made here to the CLS file.

 

If for GSEA your file looked like

 

8 4 1

# Knockout Wildtype

Knockout Knockout Knockout Knockout Wildtype Wildtype Wildtype Wildtype

 

Then for GenePattern's non-GSEA modules, it would need to be changed to

 

8 4 1

# Knockout Wildtype

0 0 0 0 1 1 1 1

 

Hope that helps! Let me know if you have further issues
