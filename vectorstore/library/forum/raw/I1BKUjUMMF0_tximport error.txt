Hi, 


For Salmon/Sailfish/Kallisto data providing the transcriptome file used to quantify the data is required and must be provided in GTF/GFF3 format. This parameter is not utilized for RSEM data. You need to supply a transcriptome database file to the "Transcriptome Database" parameter. It should be the same one gtf/gff3 file you used for your kallisto quant run.
