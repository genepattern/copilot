The 'gp_execution_log.txt' file is available on the cloud. Make sure to
click the checkbox on the job status page.
The hidden command line log uses a different naming convention,
https://cloud.genepattern.org/gp/jobResults/<jobId>/.rte.out
e.g.
    https://cloud.genepattern.org/gp/jobResults/68333/.rte.out
