Hi


it appears that you have problems in 3 of your files.


1. The class file index has to start with 0, not 1.  So in the LUSC class file, the class numbers should be 0 and 1 (not 1 and 2).  For the Melanoma class file it should be 0,1,2,3 (not 1,2,3,4).


2. In the LUSC gct file, there are 15 expression entries that are the string "#NAME?" instead of being a number.

Hi again,


we tracked down the bug and it appears that this module is not able to handle gct files where the descriptions are all blank or all the same (it tries to order the dataframe based on the description column).  So you can get around this by providing at least a few different values in the description columns of your two gct files.  In my test for the LUSC file, I just replicated the first column (gene name) into the description.  For the melanoma I only changed the first row, and with that we get past the seg fault error you have been seeing.


Once past that however we do run into a similar error generating the heatmaps.  It does generate the result file and the SA matrix, just not the two heatmaps.  I have not yet figured out a fix for this but hopefully you will get some value from having the result matrix even without the figures.


Hope this helps


Ted
