Your job ran correctly to completion but the output files are hidden, because the custom "output files" parameter you used was incorrect. For best results, run your job again, using the default value for the "output file" parameter.

Example values for the output file parameter
Correct (default value):
    <input.file_basename>.combat.<input.file_extension>
Correct (custom value):
    Park.combat.<input.file_extension>
Error (hides the output files)
    <Park>.combat.<gct>

FYI, the Module Editor documentation has more information on angle bracket (<>) substitution properties.

Regards,
