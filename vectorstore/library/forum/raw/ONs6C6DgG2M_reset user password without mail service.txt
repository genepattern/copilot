I am glad you figured out a path through.  For future reference here is what I would have suggested


0.  It is not possible for an admin to see the unencrypted password, and only the encrypted form is in the DB.  So if there is no mail server there is no good option for getting the password. 
1. If you just need another account with admin privileges, then you could add a new username to the admin group in the $GENEPATTERN_HOME/userGroups.xml file and restart the server.  Then register that new username and it will be admin after login.  As admin you can see the old jobs and files of the 'lost' user.
2. If its a private server no one else can see you could just turn off the need for passwords (require.passwords=false in genepattern.properties)


That said, deleting the account in the DB and recreating it is an even better and easier solution.
