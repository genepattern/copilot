Hi again


to be able to load it on the Notebook server you will first have to upload it to the notebook server.  Then you can use relative (or absolute) file paths from within the notebook.


To upload the file, go to your main Jupyter hub page (you can click on the big "GenePattern Notebook" logo and text at the top right of any page or notebook to get there).  Then you will see an "upload" button near the top right corner.


However if you are running the MutPanning module, it would be easier to just click the upload button for the module parameters ("mutation file*" and "sample annotation file*") since the module will be executed on the GenePattern server, not the notebook server.  Clicking on those "upload" buttons should allow you to select the files from your desktop.


Hope this helps,


Ted

Jianying,


my co-worker thinks he found the issue already.  Before re-running the module from the notebook, click on the gear icon at the top-right of the module UI and select "Advanced options" from the menu.  Then in the "Job Options" parameter group (which will appear below the other MutPanning parameters), select a memory value (e.g. 16Gb) before running the module.


We suspect this will allow it to run from the notebook.  The issue (which only affects non-administrators) is that the notebook's default of '16 Gb' does not match the expectation in the menu of "16Gb' (note no space between the 6 and the G). I will update the notebook now and we will get a fix into the next release of the GenePattern server.
