Hi Anne,


Thanks for this great question. Unfortunately, AmpliconSuite only supports paired-end WGS data, and will result in an error otherwise.


We are working on a complementary method that will work on single-end long reads (Nanopore), however it is still a couple months from being released. We'll make a note of it on the AmpliconSuite GitHub as soon as a beta version is available for testing!


Thanks,
