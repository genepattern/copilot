The dynamic drop-down feature does require an FTP server. We would like to improve the situation by making a more general API for dynamic drop-downs. This is on our radar but not yet scheduled for development. There are a few workarounds.
static dropdown - release a new version of the module each time you want to change the dropdown menu. This is simplest method. For an example look at the 'gene.sets.database' parameter on the latest version (v19.0.24) of the GSEA module.
local.choiceDirs - this server configuration property makes it possible to skip the remote FTP calls for dynamic drop-down parameters. For more details look at the config_example.yaml file in your resources directory (./resources/config_example.yaml). This requires you to maintain the files on an FTP server, however you can copy the entire contents of the ftp folder into a local directory on your server.
