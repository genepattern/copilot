Hello


There were a few things amiss:
Your file extension was incorrect. Please save your file without the .txt extension. (From a save dialog, make sure to put quotes around the file name "MyFileName.gct" ) or use the mv command in a terminal window.
The output name had an incorrect syntax. If you want to append the output name you'll want to do something like the following: "<input.dataset_basename>.gct_MyMetaInfo" (without the quotes) - this allows GenePattern to construct a valid file name.

I am not sure why but your data is not working with a jpeg output, though it does work for others I have tried. To work around this, select png from the "Output format" dropdown. If you really need it to be a jpeg you can always convert the file afterward.
Please let us know if you have any other questions or comments.


Best
-Barbara
