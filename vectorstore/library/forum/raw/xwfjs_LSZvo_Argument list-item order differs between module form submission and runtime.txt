When you create a 'Get-opt style list' for a parameter, they are passed along to the command line in the order in which they are selected. 


To workaround this problem ...
1) open the menu and click 'X Uncheck all'
2) select 'null' option
3) select other options in order ...


I expect the selections to appear in the order in which they were made in the GUI, e.g.
PROGRAM
	

null (overrides default), CollectAlignmentSummaryMetrics, CollectInsertSizeMetrics
Which should result in a properly ordered command line, e.g.
  java -jar /path/to/picard.jar CollectMultipleMetrics ... PROGRAM=null PROGRAM=CollectAlignmentSummaryMetrics PROGRAM=CollectInsertSizeMetrics  ...
