Thank you Elena,


I took a look at your file and the one difference I could notice was that the first column (the one with the ENSEMBL IDs) was not titled "Name", refer to this guide if you created your file manually: http://software.broadinstitute.org/cancer/software/genepattern/file-formats-guide#GCT -- did you use a specific tool to create this file?


I renamed that column and the error went away. I will create a ticket to make this module more robust (or at the very least provide a more helpful error message). Here is a job currently running (it's taken a while because row clustering is a compute-intensive process).


88603. HierarchicalClustering


I would like to point out that you helped me find a different bug in the code, uncentered correlation and uncentered correlation, absolute value are providing two distance metrics at once (I believe these functions are returning the confidence in the metric as well). I'll patch that formatting bug and will make a different release of the module, but this step may take a bit longer (in the order of 2-3 weeks). In the meantime, I tried using pearson correlation and the information coefficient and those functions appear to be working well (the job I linked is using pearson correlation distance for both columns and rows). Let me know if you are in urgent need of a specific distance metric and I will consider that a higher priority when testing/implementing this bug fix.


Kind regards,
Edwin.

Elena,


That is correct, you could visualize all the genes which belong to that cluster.


The question of which gene expression pattern that lead to the generation of the cluster is a bit tricker, NMF clusters based on metagenes (not directly based on the gene expression per-se), for more info you can take a look at this paper: https://www.pnas.org/content/101/12/4164. However, one thing you do is to look at which genes are differentially expressed in those clusters. For that you could use ComparativeMarkerSelection but you would need a CLS file indicating to which cluster each sample/column belongs (to create this CLS file you can use ClsFileCreator).


Kind regards,
Edwin.
