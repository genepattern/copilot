Hi Mitch,

There was a backup on the job queue. Because it's a public resource sometimes it takes longer for you job to find an available slot on the compute cluster. From the looks of things you may have cancelled that particular job (job #1735364). The best thing you can do is to reload and run the job again.

As an alternative, I suggest that you run your jobs on the new GenePattern Server hosted in the cloud on AWS:
    https://cloud.genepattern.org/gp/
Connect with the same username/password that you use on the public GP server.

We are moving users and modules over to this server in the coming months. I welcome you to join now as an early adopter.

Regards,
Peter
