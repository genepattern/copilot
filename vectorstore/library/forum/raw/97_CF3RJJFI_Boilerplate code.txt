Hello,


The best suggestion I have is to create a helper package that you can import, which lazily creates the local directions when imported and which lists py4cytoscape as a dependency, so that it is automatically installed alongside the helper package. Doing things this way gets rid of some of those pain points. It still, however, requires that all of your notebooks import the helper package, which is a basic limitation of the Python global namespace.
