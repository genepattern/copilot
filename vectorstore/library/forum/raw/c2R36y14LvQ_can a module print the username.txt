Yes. Use the <userid> substitution variable. For example, the attached
module saves the current userid into the <output.filename>.
Enter this commandLine in the GUI
echo "userid=<userid>" \> <output.filename>

Note: the "\>" redirects output to the named file. Use an additional '\'
as an escape character when editing the manifest file directly. E.g.
commandLine=echo "userid\=<userid>" \\> <output.filename>

For testing, I use a general purpose echoCmd module,
commandLine=echo <arg>
At runtime I add various substitution params as args, e.g.
The userid substitution: <userid>

Regards,
Peter
