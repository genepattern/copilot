Hi,  sorry you are having trouble with this.  Uploads to GenePattern are routed through Amazon Web Services' S3 servers.  When we have had other users with this problem the issue was typically transitory and between their laptops and S3.  So first try again to upload a file.  You could use the ConvertLineEndings module to test if uploads are working as it will accept any text file as input.


If that is still not working, can you tell me what your local environment is?  e.g. Are you at a private residence, a University or a for-profit company.  Sometimes network restrictions at commercial organizations prevent the connection.


Ted
