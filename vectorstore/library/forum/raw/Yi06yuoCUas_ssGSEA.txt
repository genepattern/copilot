Hello,

 

This issue is caused when none of the gene identifiers in your dataset match the gene symbols in the Gene Set. You’ll want to remap the identifiers in the dataset so that they match the gene set. This can be done using the CollapseDataset module with a CHIP file that matches the type of IDs used in the input file. We offer CHIP files for many different input identifier types. They’re available from here: https://data.broadinstitute.org/gsea-msigdb/msigdb/annotations_versioned/

(The ones versioned MSigDB.7.2 are the latest build).
