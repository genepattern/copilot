Hello Yujin,



It's nice to hear from you!



We are still updating GenePattern (we are currently on 3.9.11-prerelease 11), but this is not a full production release which is why it is not on the downloads page.


We have been focusing on the incremental changes, large and small, for our move to the Amazon cloud for our publicly hosted server, and haven't made any significant changes to the code base which impacts a locally installed server.


In the next year we will do a full production release which includes support for running GenePattern modules in a local Docker, as this is now the current best practice for releasing and running modules in GenePattern.



Sadly, the download page is rather out-of-date and is slated for a renovation in the new year, but as a stop-gap, I'll talk to the team about adding a link indicating that interim and pre-release builds are available in our GitHub repository - which is now the unfiltered "truth" as far as our release process goes.


Thanks for writing in and bringing this to our attention!


All the best,

Barbara

Our current best practice is to run modules in docker containers. As a matter of fact, docker is required on the new public GenePattern Server running in the cloud. See this blog post for general information on the migration to the cloud:
    http://software.broadinstitute.org/cancer/software/genepattern/blog/2018/10/25/genepattern-is-moving-to-the-cloud

This means that the "Programming Language" page is no longer relevant. Our developer documentation and admin pages are not yet up to date. We have been mostly focusing our attention on the end users. I suggest starting with a 3.9.11 release candidate. This comes out-of-the-box configured for docker integration. A few additional steps are required, depending on which module and which OS you are using.

What OS are you using for your local server?

The release candidates are available for download from GitHub ...
    https://github.com/genepattern/genepattern-server/releases


Regards,
Peter
