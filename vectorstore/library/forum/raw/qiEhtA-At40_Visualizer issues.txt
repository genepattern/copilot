Jay,


the problem is probably that the version of java that you are using to run the VisualizerLauncher is older (as is the launcher) and needs to have its keystore certificates updated.  There are a lot of variations in this for OS, Java version etc, but this page seems to do a good job of walking you through the steps.


https://medium.com/expedia-group-tech/how-to-import-public-certificates-into-javas-truststore-from-a-browser-a35e49a806dc


Hope this helps,
