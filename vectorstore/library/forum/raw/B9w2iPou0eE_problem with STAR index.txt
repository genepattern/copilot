I have noticed that there is a problem with STAR.aligner in https://cloud.genepattern.org/. The interface says :
Select a prebuilt index from https://datasets.genepattern.org/?prefix=data/module_support_files/STAR/

Howevern, when I try, I get
Unable to connect to https://datasets.genepattern.org/data/module_support_files/STAR/Homo_sapiens.UCSC.hg38/Genome.zip. 
When I try instead 
https://datasets.genepattern.org/?prefix=data/module_support_files/STAR/Arabidopsis_thaliana.Ensembl.TAIR10/

now it starts running but fails. The reason is that the zip file contains the files of the STAR index, but to make it work (I understand you are using code from V.I.B.) the zip file should contain a folder with inside that folder the files of the index and the name of the folder shall appear on the command line. I suggest you change the indices or change the code.
