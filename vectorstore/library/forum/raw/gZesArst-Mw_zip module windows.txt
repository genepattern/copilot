Hello,


As I mentioned we are working on a version of GenePattern that will run inside a Docker container, but we are not ready to release any of that at this time.


You could try the last build we made of GenePattern for Windows in March of 2015, but we haven't tested it since then, so it may not work, or may not work with your module.


https://github.com/genepattern/genepattern-server/releases/tag/GenePattern_3.9.2


If you simply want to run the code in the module, independent of GenePattern, you can look at the command line in the manifest, as well as it's dependencies and from there re-construct a command line and environment that you could run in a terminal.


Is this a module that you wrote?


Best
-Barbara
