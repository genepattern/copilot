Diana,


this does seem to be a problem with the HeatMapImage module.  We will look into it and see what we can do to correct it.  In the meantime, I verified that your gct file can run on the HeatMapViewer visualization.  It will allow you to save the heatmap as either a png or svg file.  As this runs in a browser interactively, it may not be ideal for a pipeline, but if you only have a few files to generate images for it might suffice until we have a fix.


Hope this helps


Ted

Hi Diana, 


The issue, unfortunately, was still with your file. You had saved it as a text file with a ".txt" suffix. To fix this in the future, make sure you save your .gct files with quotes around them to prevent your computer from added a .txt ending. 
"myfile.gct" vs myfile.gct in the save dialog.
